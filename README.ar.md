Harkback إضافة لمتصفح Chrome لمن يقرؤون الأوراق البحثية والمستندات التقنية. حدّد مصطلحًا فتشرحه الإضافة في سياقه. يُحفَظ كل شرح في سجل محلي لا يُعدَّل بل يُضاف إليه فقط. وعندما يظهر المصطلح نفسه في صفحة لاحقة، حتى لو كُتب بصيغة أخرى، يضع Harkback خطًا تحته ويعرض لك ما فهمتَه في المرة السابقة.

> "harken back": العودة إلى نقطة سابقة.

## البدء السريع

```sh
git clone https://github.com/zestworks-io/harkback.git && cd harkback
pnpm install && pnpm --filter @harkback/extension build
```

افتح `chrome://extensions`، وفعّل **وضع المطوّر (Developer mode)**، واختر **تحميل إضافة غير مضغوطة (Load unpacked)** ثم حدّد `apps/extension/.output/chrome-mv3`. بعد ذلك اختر نموذجًا:

<details open>
<summary><b>نموذج محلي (مجاني)</b></summary>

ثبّت [Ollama](https://ollama.com)، ونزّل نموذجًا، ثم اختر **Ollama** في صفحة الإعداد الأول. استخدم _اختبار الاتصال_ لتحصل على الأمر الوحيد الذي يسمح للإضافة بالاتصال. لا يغادر شيء حاسوبك.

</details>

<details>
<summary><b>نموذج مستضاف (بمفتاح API خاص بك)</b></summary>

اختر OpenAI أو Anthropic أو Google Gemini أو xAI Grok أو DeepSeek أو Qwen أو Moonshot (Kimi) أو Zhipu GLM أو Mistral أو OpenRouter، أو عنوانًا مخصصًا متوافقًا مع OpenAI، والصق مفتاحك. يحاسبك المزوّد مباشرة؛ ولا يوجد خادم لـ Harkback بينكما.

</details>

بعد ذلك حدّد مصطلحًا في أي صفحة واضغط `Alt+Shift+E`. انظر [التثبيت](#التثبيت) و[ربط نموذج](#ربط-نموذج) للتفاصيل.

## لماذا لا تسأل ChatGPT فحسب؟

يمكنك لصق مصطلح في روبوت محادثة والحصول على إجابة جيدة. لا يحاول Harkback تقديم إجابة أفضل. إنه يضيف ما تفتقر إليه نافذة المحادثة: **الذاكرة**. يتحول كل مصطلح تبحث عنه إلى سجل مرتبط بالصفحة والاقتباس والتاريخ، وتترابط السجلات في شبكة معرفة تخصّك أنت.

|                        | سؤال روبوت محادثة                           | Harkback                                                                        |
| ---------------------- | ------------------------------------------- | ------------------------------------------------------------------------------- |
| **السياق**             | تنسخ المصطلح وبعض النص وتنتقل بين التبويبات | تحدّد المصطلح في الصفحة؛ فتذهب معه فقرته وقسمه، ويُتحقَّق من الاقتباس           |
| **في المرة القادمة**   | تبدأ محادثة جديدة فارغة، أو تنسى أنك سألت   | يُوضَع خط تحت المصطلح في الصفحات اللاحقة، مع ما فهمتَه في المرة السابقة         |
| **البنية**             | كومة من نصوص المحادثات                      | مفاهيم لها أسماء بديلة ومتطلبات سابقة وصيغ متفرعة ومصطلحات ذات صلة              |
| **الاحتفاظ بالمعلومة** | لا شيء                                      | قائمة مراجعة يجدولها نموذج للذاكرة: يعود كل مصطلح قبل أن تنساه بقليل            |
| **سجلاتك**             | تعيش في حساب المزوّد                        | تبقى في متصفحك؛ وتصدّرها بصيغة Markdown أو ملاحظات Obsidian أو JSONL            |
| **النموذج والتكلفة**   | خدمة واحدة وخطة واحدة                       | أي نموذج من النماذج المدعومة: Ollama المحلي مجاني، أو استخدم مفتاح API الخاص بك |

Harkback مجاني ومفتوح المصدر (Apache-2.0)، ولا خادم له ولا اشتراك. لكنه يحتاج إلى نموذج يكتب الشروح: النموذج المحلي مجاني، أما المستضاف فيحاسبك عليه مزوّده على مفتاحك أنت.

## الميزات

- **شرح في السياق.** حدّد مصطلحًا، وانقر _اشرح_ أو اضغط `Alt+Shift+E`. تتدفق الإجابة من النموذج الذي ضبطته، وتُوسَم بأنها _معرَّف في المصدر_ (تعرّف الصفحة المصطلح، ويُتحقَّق من الاقتباس مقابل نص الصفحة) أو _معرفة خارجية_.
- **التذكّر.** يُخزَّن كل شرح وكل سؤال متابعة وكل علامة «فهمت / ما زلت لا أفهم» على هيئة حدث في IndexedDB. ولا يغادر متصفحك شيء سوى طلب النموذج الذي تُطلقه.
- **محادثات المتابعة.** اسأل المزيد على البطاقة؛ يبقى كل سؤال فوق إجابته، وتُحفَظ المحادثة مع الشرح. يعرضها السجل كاملة، ويجدها البحث. وتُرسَم المعادلات.
- **اللقاءات المتجددة.** في الصفحات اللاحقة تُوضَع خطوط تحت المصطلحات التي بحثتَ عنها. مرّر المؤشر لترى متى وأين صادفتَ المصطلح وما فهمتَه، وسطرًا يبيّن أي نص في الصفحة طابقه، ثم علّمه «تذكّرته» أو اشرحه من جديد أو قارن بين الاستخدامين أو اكتمه.
- **مفهوم واحد وصيغ كتابة كثيرة.** `LLM` و`LLMs` و`the LLM` و`large language model` و`Large-Language Models` هي المفهوم نفسه. وكذلك `β-VAE` و`beta-VAE`، و`fine-tuning` و`ﬁne-tuning` بحرف مركّب. وتُعرَض عليك المطابقات القريبة بسؤال «هل هذا هو المصطلح الذي بحثتَ عنه قبل 3 أيام؟».
- **مصطلحات ذات صلة.** إذا قال نموذج إن `QLoRA` صيغة متفرعة من `LoRA`، فإن صفحة تذكر `QLoRA` فقط تذكّرك بما فهمتَه عن `LoRA`.
- **صفحات المفاهيم.** افتح أي مصطلح من السجل لترى مدى فهمك له، والأسماء التي يقترحها النموذج بلغتك (وتقبلها أو ترفضها)، وما يبني عليه (المتطلبات السابقة)، وصيغه المتفرعة والمصطلحات ذات الصلة، وكل مرة صادفتَه فيها. ويمكنك إضافة اسم بديل، أو دمج مفهومين متطابقين، أو إزالة علاقة خاطئة، أو كتم مصطلح.
- **المراجعة.** يعرض السجل زر _مراجعة_ مع عدد المصطلحات المستحقة. يُجدوَل كل مصطلح بواسطة [FSRS-7](https://github.com/open-spaced-repetition/fsrs4anki)، وهو نموذج للذاكرة: قيّم الإجابة بـ _مرة أخرى_ أو _صعب_ أو _جيد_ أو _سهل_ فيعود المصطلح قبل أن تنساه بقليل، فتتباعد المصطلحات السهلة بسرعة وتعود الصعبة قريبًا. ويبيّن كل زر متى سيعود المصطلح. ويمكنك كتابة ما تتذكره قبل إظهار الشرح، وزر اختياري **تحقق من إجابتي** يسأل نموذجك عن مدى قربك من الصواب (يقترح درجة فقط؛ والقرار لك، ويمكنك إيقافه من الإعدادات). وتعمل المراجعة كلها بلوحة المفاتيح: `Space` يُظهر الشرح، و`1`–`4` للتقييم، و`S` للتخطي. وتأتي المصطلحات التي تبني على غيرها بعد متطلباتها السابقة إذا استحق الاثنان معًا، ويشير المصطلح الذي تتعثر فيه إلى المتطلبات السابقة التي قد تكون ناقصة. وتذكّر مصطلح على تلميح لقاء يُحتسب مراجعة خفيفة. ويحدد إعداد مدى رغبتك في تذكّر المصطلح عندما يحين موعده (90% افتراضيًا). وتعرض أيقونة شريط الأدوات عدد المصطلحات المستحقة.
- **ملخص أسبوعي.** يعرض السجل ← _الملخص الأسبوعي_ ما صادفتَه في أسبوع: المصطلحات الجديدة وما أُعيدت زيارته، والإجابات، والمصطلحات التي ما زالت مربكة لك، وأين قرأتَ، والروابط الجديدة بين المفاهيم. يُبنى على حاسوبك من سجلاتك ولا يستدعي أي نموذج.
- **يبني على ما تعرفه.** عندما يكون المصطلح الذي تبحث عنه قريبًا من مصطلح تفهمه بالفعل، يُخبَر النموذج بذلك فيستطيع شرح الفرق بدل البدء من الصفر.
- **خصوصية بالتصميم.** يقتصر الفحص التلقائي على arxiv.org إلى أن تضيف مواقع؛ ويضيف زر واحد في الإعدادات مواقع البحث الشائعة. ويمكن إجبار المواقع الحساسة على استخدام نموذج محلي، ولا تسجّل النوافذ الخاصة ولا تفحص أبدًا.
- **سجلات قابلة للنقل.** صدّر كل شيء بصيغة Markdown، أو بطاقات Anki، أو مجلد ملاحظات مترابطة (ملف لكل مفهوم مع `[[روابط]]`، جاهز لـ Obsidian؛ وما تكتبه تحت سطر العلامة يبقى بعد التصدير التالي)، أو سجل أحداث JSONL مُرقَّم الإصدار بمخطط JSON منشور. ويُكتب نسخ احتياطي أسبوعي بصيغة JSONL في `Downloads/harkback`، ويستعيده **استيراد JSONL** في السجل (تُتخطّى السجلات الموجودة لديك). ويمكن لإعداد أن يستبعد المصادر الحساسة من النسخ الاحتياطية والتصدير.
- **إيقاف وإعادة محاولة وتبديل النماذج.** ينهي زر _إيقاف_ الإجابة أثناء كتابتها. وبعد الفشل تعرض البطاقة _حاول مرة أخرى_، ومع ضبط عدة نماذج تعرض _جرّب باستخدام…_ لكل نموذج من الباقي.
- **معاينة الصفحة قبل قراءتها.** انقر زر شريط الأدوات أو اضغط `Alt+Shift+P` أو استخدم قائمة النقر الأيمن، فيعرض Harkback فحص الصفحة مع ذكر النموذج وهل هو بعيد؛ ولا يُرسَل شيء حتى توافق. يلتقط استدعاء نموذج واحد المصطلحات الأساسية في الصفحة، وتصنّفها سجلاتك إلى _ما زال مربكًا_ و_بدأ يُنسى_ و_جديد عليك_ و_تعرفه_. وتعرض _المعاينة_ شرحك السابق لمصطلح تعرفه، أو شرحًا قصيرًا كتبه النموذج لمصطلح جديد، ولا تسجّل شيئًا. ولا يرى النموذج سوى نص الصفحة، ولا يرى قائمة مفاهيمك أبدًا، والصفحة الحساسة لا تستخدم سوى نموذج محلي. ويقرأ الفحص أول 16000 حرف من الصفحة ويخبرك عندما تُقتطَع صفحة أطول.
- **ترجمات YouTube.** أضِف YouTube في الإعدادات ومع تفعيل الترجمات توضَع خطوط تحت المصطلحات التي بحثتَ عنها من قبل في سطر الترجمة. أوقف الفيديو وحدّد مصطلحًا لشرحه من الترجمات التي شاهدتَها. ويُسجَّل البحث مع موضع التشغيل (`12:34`)، ويربطك السجل والمراجعة والتصدير بتلك اللحظة. معطّل حتى تضيف الموقع؛ ولا يُنزَّل شيء، ويُقرأ فقط سطر الترجمة المعروض على الشاشة.
- **GitHub وNotion وGoogle Docs.** أضِف الموقع في الإعدادات فتُقرأ صفحاته بحسب تخطيطها الخاص: ملف README لمستودع، ومحادثة issue أو pull request، وصفحة Notion، وعرض منشور أو عرض جوال لمستند Google. المستند مصدر واحد مهما كانت طريقة وصولك إليه، ولا يُقرأ سوى نصه هو، لا القوائم المحيطة به.
- **يسأل قبل إرسال صفحة خاصة.** الصفحة التي تبدو خاصة، مثل مستودع GitHub خاص أو صفحة Notion أو Google Docs غير منشورة، لا تُرسَل إلى أي نموذج حتى تختار _محلي فقط_ أو _أرسل على أي حال_. ويعرض قفل في زاوية الصفحة الحالة ويغيّرها؛ ويُسجَّل اختيارك ويمكن تذكّره للموقع.
- **عدة طرق للبدء.** حدّد نصًا وانقر _اشرح_ (تحديدات الفأرة أو لوحة المفاتيح أو اللمس)، أو اضغط `Alt+Shift+E`، أو استخدم _اشرح_ في قائمة النقر الأيمن. وتُعاد قراءة الصفحات التي تحمّل مزيدًا من النص أو تنتقل إلى صفحة أخرى دون إعادة تحميل.
- **اختيارك للنموذج.** نموذج Gemini Nano المضمَّن في Chrome (على حاسوبك ولا يحتاج إلى ضبط)، وOllama، وOpenAI، وAnthropic، وGoogle Gemini، وxAI Grok، وDeepSeek، وQwen، وMoonshot (Kimi)، وZhipu GLM، وMistral، وOpenRouter، أو أي خادم متوافق مع OpenAI. يستخدم Anthropic وGemini واجهتيهما الأصليتين.

## شبكة معرفتك

يضيف كل بحث إلى شبكة مما قرأته، تُبنى من قراءتك أنت لا من ذاكرة نموذج عام.

- **المفاهيم هي العُقد.** `LoRA` عقدة واحدة، أيًّا كانت صيغة كتابته في الصفحة (`LoRA` أو `low-rank adaptation`)، وبأي لغة صادفتَه. وتحتفظ العقدة بأسمائها البديلة ومجالها ومدى فهمك لها.
- **العلاقات هي الحواف.** يقترح نموذج روابط `variant_of` و`prerequisite` و`related` عندما تبحث عن مصطلح، مثل أن `QLoRA` صيغة متفرعة من `LoRA`. ويمكنك إزالة رابط خاطئ، أو دمج مفهومين متطابقين، أو إضافة اسم بديل.
- **كل شيء يشير إلى دليله.** يسرد المفهوم كل مرة صادفتَه فيها: الصفحة والاقتباس والتاريخ وشرحك ومحادثة المتابعة.
- **الشبكة تؤدي عملًا.** صفحة تذكر `QLoRA` فقط تذكّرك بـ `LoRA`، ويُخبَر النموذج بما تعرفه ليشرح الفرق، وتُجدوَل المراجعة لكل مفهوم.
- **إنها لك.** صدّر مجلد ملاحظات مترابطة (`[[روابط]]`، ملف لكل مفهوم) وافتحه في Obsidian لترى الشبكة هناك، أو صدّر سجل الأحداث الكامل بصيغة JSONL.

افتح **المخطط** في السجل لتراه على هيئة خريطة: مفاهيم ملوّنة بحسب مدى فهمك لها (تم فهمه أو غير راسخ أو مربك أو جديد)، مع أسهم للمتطلبات السابقة والصيغ المتفرعة. رشّح بحسب المجال أو مستوى الفهم أو وقت آخر بحث عن المصطلح. اسحب للتحريك، ومرّر للتكبير، وانقر مفهومًا لفتحه. ويمكنك أيضًا تصفحها عبر صفحات المفاهيم، وعبر Obsidian بعد التصدير.

## كيف يعمل

```
 read                explain                 remember                 recall
 ────                ───────                 ────────                 ──────
 content script  →   background worker   →   append-only event log →  matcher scans the next page
 extracts page       routes to a model       (IndexedDB), replayed      for known names, picks the
 text, tracks        by site sensitivity,    into concepts, aliases     concepts worth showing, and
 your selection      streams the answer,     and encounters             draws the underline + card
                     resolves the concept
```

1. **القراءة.** يستخرج content script النص المقروء من الصفحة (بنية LaTeXML في arXiv، وReadability في غيره) ويحتفظ بخريطة من مواضع النص إلى عقد DOM.
2. **الشرح.** يتحقق العامل الخلفي (background worker) من قواعد المواقع، ويختار نموذجًا، ويطبّق حدًّا محليًا للمعدّل، ويرسل المصطلح مع فقرته. وتسرد التعليمات المفاهيم المعروفة مرشّحين ليقول النموذج «هذا هو المفهوم نفسه c1». وتُحلَّل الإجابة بتسامح: تُحتمَل البطاقات المقطوعة والفواصل الزائدة والتسميات المزخرفة.
3. **التذكّر.** تتحول النتيجة إلى أحداث (`concept.created` و`encounter.created` و`edge.proposed` وغيرها). وتُشتقّ المفاهيم والأسماء البديلة وعمليات الدمج بإعادة تشغيل السجل ولا تُخزَّن أبدًا، فتحسّن قاعدة مطابقة أفضل السجلات القديمة أيضًا.
4. **الاسترجاع.** في كل صفحة يفحص مطابِق Aho-Corasick النص بحثًا عن كل اسم واختصار معروف. ثم يطبّق اختيار تلميحات اللقاء القواعد التي تُبقيه مفيدًا: ليس في الصفحة التي بحثتَ فيها عن المصطلح، وليس خلال فاصل أدنى، وتبقى المفاهيم المكتومة مكتومة، ويحتاج الاختصار الملتبس إلى مصطلح ثانٍ من المجال نفسه في الصفحة.

## التثبيت

يتطلب Node 22 أو أحدث و[pnpm](https://pnpm.io). لا توجد صفحة في المتجر بعد، لذا حمّل الإضافة من المصدر:

```sh
# from the repository root
pnpm install
pnpm --filter @harkback/extension build
```

افتح `chrome://extensions`، وفعّل **وضع المطوّر (Developer mode)**، واختر **تحميل إضافة غير مضغوطة (Load unpacked)**، وحدّد `apps/extension/.output/chrome-mv3`. وتُفتَح صفحة الإعداد الأول عند التثبيت.

**Microsoft Edge.** شغّل `pnpm build -b edge` في `apps/extension` (أو `pnpm zip:edge`)، وافتح `edge://extensions`، وفعّل **وضع المطوّر**، واختر **تحميل إضافة غير مضغوطة** وحدّد `apps/extension/.output/edge-mv3`. قد لا يوفّر Edge نموذج Chrome المضمَّن؛ فاختر نموذجًا آخر في الإعداد.

## الخصوصية

- عندما تطلب شرحًا، يذهب النص المحدد وفقرته والقسم وعنوان الصفحة إلى خدمة النماذج التي ضبطتها، وفق شروط ذلك المزوّد.
- في المراجعة، يرسل الزر الاختياري **تحقق من إجابتي** المصطلح وإجابتك المكتوبة وشرحه المخزَّن إلى نموذجك، ولا يفعل ذلك إلا عند الضغط عليه. أوقفه من الإعدادات فلا يظهر الزر أبدًا. ويتبع قواعد النموذج والمصادر الحساسة نفسها التي يتبعها الشرح.
- تبقى السجلات في هذا المتصفح. وتحتوي النسخ الاحتياطية على السجلات فقط، ولا تحتوي أبدًا على الإعدادات أو مفاتيح API.
- تُفحص الصفحات تلقائيًا في arxiv.org فقط. وفي غيره عليك النقر على الزر أو الضغط على `Alt+Shift+E` أو السماح بالموقع.
- لا يُرسَل أبدًا محتوى مصدر حساس إلى نموذج غير محلي، بما في ذلك كسياق لمقارنات لاحقة. ويُعدّ الخادم على شبكتك الخاصة غير محلي. ويبقى المصدر حساسًا إلى أن تضع عليه علامة «عادي» في إدخاله في السجل.
- الصفحة التي تبدو خاصة (مستودع GitHub خاص؛ أو صفحة Notion أو Google Docs غير منشورة) لا تُرسَل إلى أي نموذج حتى تختار. والصفحات التي لا يحدد الموقع حالتها بأي اتجاه يُسأل عنها في Notion وGoogle Docs، ولا يُسأل في GitHub. وما تقوله الصفحة عن نفسها مجرد تلميح، فضع علامة «حساس» على الموقع عندما يكون الأمر مهمًا.
- يستبعد إعداد المصادر الحساسة من النسخ الاحتياطية والتصدير.
- تشرح النوافذ الخاصة ولا تسجّل ولا تفحص ولا تعرض تلميحات اللقاء أبدًا.
- تعيش خطوط تلميحات اللقاء في الصفحة، لذا قد تستنتج نصوص الصفحة نفسها المصطلحات التي لديك سجلات عنها.
- يؤدي حذف شرح إلى إزالته داخل التطبيق؛ وقد تبقى آثار على القرص، ولا يمكن استرجاع النسخ الاحتياطية المُصدَّرة.
- تُخزَّن مفاتيح API **دون تشفير** في مساحة تخزين الإضافة.

الملاحظات المعروضة في الإضافة هي المرجع المعتمد: [`apps/extension/src/lib/pages/privacy.ts`](apps/extension/src/lib/pages/privacy.ts).

## القيود

- Chrome وMicrosoft Edge (Manifest V3). ولا يُدعَم Firefox وSafari. ونموذج Chrome المضمَّن غير متاح في كل متصفح؛ ويحتاج Edge إلى نموذج آخر.
- تعتمد الشروح على النموذج الذي تختاره؛ وقد تُنتج النماذج المحلية الصغيرة بطاقات مفاهيم أضعف، مما يخفض جودة الاسترجاع لكنه لا يُعطّل التسجيل أبدًا.
- لا يمكن قراءة نص عارض PDF المدمج في المتصفح، لذا يفتح Harkback ملف PDF في صفحة قراءة خاصة به (وتذهب أوراق arXiv إلى نسخة HTML بدلًا من ذلك). وتُقرأ ملفات PDF الممسوحة ضوئيًا بالتعرف الضوئي (OCR) على حاسوبك (الإنجليزية مضمَّنة؛ وكل لغة أخرى تنزيل واحد من `jsdelivr.net`)، وهو أبطأ وأقل دقة من النص الحقيقي ولا يستعيد الخط اليدوي أو المعادلات أو الجداول، وتحديد الفقرات في التخطيطات المعقدة (الجداول والأشكال التي تحوي نصًا وثلاثة أعمدة أو أكثر) تقريبي. ويحتاج ملف PDF على حاسوبك إلى موافقتين: فعّل «السماح بالوصول إلى عناوين URL للملفات» لـ Harkback في `chrome://extensions`، ثم انقر «السماح بالملفات المحلية» في صفحة القارئ أول مرة.
- تحتاج مطابقة الاختصارات تلقائيًا إلى ثلاث كلمات على الأقل في الاسم الكامل (`LLM` من `Large Language Model`). ويُحتفَظ باختصارين يشيران إلى اسمين كاملين مختلفين في المجال نفسه (مثل «GNN» مختلفين) كمفهومين منفصلين.
- تُوضَع خطوط تحت الأسماء الصينية، والأسماء اليابانية المكتوبة بالكانجي فقط، التي تتألف من ثلاثة أحرف أو أكثر أينما ظهرت. أما الاسم المكوّن من حرفي هان فيوضع خط تحته فقط حيث يراه قاموس المتصفح كلمة قائمة بذاتها في الصفحة، وهذا يحتاج إلى متصفح يدعم `Intl.Segmenter`؛ والاسم المكوّن من حرف واحد لا يُطابَق أبدًا. والأسماء التي فيها كانا أو هانغول تحتاج إلى حرفين. وتُعدّ الكتابتان المبسّطة والتقليدية للحروف التقنية الشائعة مصطلحًا واحدًا. ولا تُطابَق الكاتاكانا نصف العرض مع علامة تشكيل منفصلة.
- YouTube: لا تُقرأ سوى صفحات `www.youtube.com/watch` التي فُعّلت فيها الترجمات (CC)، ولا يتوفر كسياق سوى أسطر الترجمة التي عرضها المشغّل منذ فُتحت الصفحة. وغالبًا ما تُخطئ الترجمات المولّدة تلقائيًا في كتابة المصطلحات التقنية، والمصطلح المكتوب خطأ لا يطابق سجلاتك. ولا يُدعَم Shorts ولا المشغّلات المضمَّنة في مواقع أخرى ولا وضع ملء الشاشة (يخفي المشغّل تلميحات Harkback؛ فاستخدم وضع المسرح)، وقد يوقف تغيير YouTube لصفحته قراءة الترجمات إلى أن يُحدَّث Harkback.
- GitHub وNotion وGoogle Docs: لا تُقرأ سوى الصفحات الرئيسية للمستودعات وissues وpull requests (لا ملفات الشيفرة)، وصفحات Notion، ومستندات Google في عرضها المنشور أو عرض الجوال. يعرض Notion الكتل التي رسمها فقط، لذا قد تُقرأ صفحة طويلة جزئيًا. ويرسم محرر Google Docs نصه رسمًا فلا يمكن قراءته، ولم يُفحَص عرض المعاينة. وتغيّر هذه المواقع تخطيطها دون إشعار؛ وعندما لا يتعرف Harkback على أحدها يقرأ الصفحة كأي صفحة أخرى إلى أن يُحدَّث.
- تُهمَل علامات التشكيل في المطابقة («résumé» و«resume» مصطلح واحد)، لكن لا يوجد اشتقاق (stemming) للغات غير الإنجليزية، لذا فصيغ التصريف مثل جموع الألمانية مصطلحات منفصلة. وفي العربية تُهمَل الحركات والتطويل وفروق كتابة الألف والياء والتاء المربوطة، ويوضع خط أيضًا تحت الاسم مع بوادئ الحرف الواحد وأداة التعريف (`و` و`ب` و`ل` و`ال` و`بال`) ومع لواحق الجمع والضمائر الشائعة؛ ولا يُتعرَّف على غير ذلك من التصريف.
- الواجهة بالإنجليزية افتراضيًا، وهي متاحة أيضًا بالصينية المبسطة والتقليدية واليابانية والكورية والإسبانية والفرنسية والألمانية والبرتغالية البرازيلية والعربية (من اليمين إلى اليسار؛ ترجمة آلية لم يراجعها متحدث أصلي). ويمكن كتابة الشروح بـ 16 لغة، تُختار على حدة في الإعدادات. وتستخدم الملاحظات المصدَّرة وMarkdown تسميات بالإنجليزية أو الصينية فقط.

| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/spec`  | صيغة الأحداث: الثوابت ومخططات zod ومخطط JSON المُولَّد.                                                                                |
| `packages/core`  | المنطق الخالص: إعادة التشغيل وتطبيع الأسماء ومطابقة المفاهيم واختيار تلميحات اللقاء والتعليمات وتحليل المخرجات وتصدير JSONL وMarkdown. |
| `apps/extension` | إضافة Chrome، مبنية بـ [WXT](https://wxt.dev): content script وbackground worker والسجل والإعدادات والإعداد الأول.                     |
| `tools/lint`     | إعداد ESLint.                                                                                                                          |
| `guide`          | التوثيق: دليل المستخدم والنماذج والخصوصية والبنية وصيغة البيانات.                                                                      |

## التطوير

```sh
pnpm install
pnpm --filter @harkback/extension dev     # live reload
```

قبل فتح pull request:

```sh
pnpm typecheck     # all packages
pnpm lint          # ESLint
pnpm test          # unit tests
pnpm check:build   # production build: manifest permissions and content-script size
pnpm e2e           # end-to-end tests in Chromium (run `pnpm exec playwright install chromium` once)
pnpm format:check  # formatting
```

لتجهيز إصدار لـ Microsoft Edge Add-ons شغّل `pnpm zip:edge` (انظر `store/edge/README.md`). ولتجهيز إصدار لمتجر Chrome الإلكتروني، ارفع `version` في `apps/extension/package.json`، ثم شغّل `pnpm release`. فهو يُجري الفحوص ويبني الإضافة للإنتاج ويتحقق من الحزمة ويكتب `apps/extension/.output/harkback-<version>-chrome.zip`. واستخدم `tools/package.sh --skip-checks` لبناء ملف zip فقط.

تحمّل اختبارات الطرف إلى الطرف (end-to-end) الإضافة المبنية في Chromium، وتخدم صفحات arXiv من `apps/extension/fixtures`، وتتحدث إلى خادم نموذج وهمي محلي. وهي تغطي الدورة كلها: قراءة ورقة، والشرح، والتسجيل، وصفحة السجل، وتلميحات اللقاء في أوراق أخرى. انظر `apps/extension/e2e`.
