# Chrome 線上應用程式商店詳細資訊：繁體中文

**名稱：** Harkback

**摘要**（不超過 132 個字元）：
閱讀時解釋術語，記住你理解了什麼，再次遇到時自動想起。記錄保存在本機，使用你自己的模型。

**類別：** 工作效率

**語言：** 中文（繁體）

## 詳細說明

Harkback 適合閱讀論文和技術文件的人。選取一個術語，它會結合你正在讀的段落解釋這個術語。每則解釋都保存在你的瀏覽器裡。之後在別的頁面再遇到同一個術語，即使寫法不同，Harkback 也會加底線，並顯示你上次的理解。

它不想成為更好的聊天機器人，而是補上聊天視窗缺少的東西：記憶。

使用方式
• 選取術語，點擊「解釋」、使用右鍵選單，或按 Alt+Shift+E。解釋會結合術語所在的段落和章節；原文給出定義時，會引用原文。
• 複習你沒把握的術語。Harkback 用 FSRS-7 記憶模型安排複習：替自己選「沒記住」「勉強記得」「記住了」或「很輕鬆」，每個術語會在你快要忘記之前回來。互相依賴的術語會依正確的順序複習，沒弄懂的術語會指出你可能缺少的前置概念。
• 讀之前先預覽一頁：看看其中哪些關鍵術語對你是新的，哪些你已經懂了。
• 在之後的頁面上，你查過的術語會加底線。懸停即可看到之前的解釋、在哪裡遇到過、當時理解得如何。縮寫和全稱互相比對（「LLM」與「Large Language Model」）。
• 在任何卡片上繼續追問，對話會和解釋一起保存。可以中途停止回答，模型出錯時也可以換一個模型重試。
• 你的記錄構成一張知識圖譜：概念、別名、前置概念、變體和相關術語。可以搜尋、複習、以地圖形式檢視，也可以匯出為 Markdown 筆記（帶 [[連結]]，適用於 Obsidian）、Anki 卡片，或可再次匯入的 JSONL 備份。

PDF 與論文
arXiv 論文自動可用。其他 PDF 會在 Harkback 自帶的閱讀器中開啟，公式會排版。掃描版 PDF 在你捲動時用本機 OCR 辨識，之後和一般文字一樣使用。內建英文，其他語言從清單中下載一次即可。其他網站只有在你點擊工具列按鈕或允許該網站時才會掃描。在「設定 → 網站」中還可以新增 GitHub（README、issue 和 pull request）、Notion、Google 文件（已發布或行動版檢視）和 YouTube 字幕，也可以一鍵新增 bioRxiv、PubMed、OpenReview 等常用研究網站。

模型由你選擇
Harkback 沒有伺服器，也不需要帳號。你連接自己的模型：可以是在你電腦上執行的模型（文字不會離開你的電腦），也可以是你用自己的 API key 使用的雲端服務。你自己區域網路內的模型也可以。Chrome 內建模型（Gemini Nano）在你的電腦上執行，無需任何設定。它是小模型，比雲端模型慢，適合簡短的解釋。

隱私
• 你的記錄保存在瀏覽器裡，開發者不會收到任何資料。
• 只會把你觸發的內容傳送給你設定的模型：解釋時是選取的文字、所在段落、章節和頁面標題；預覽頁面時是頁面文字；「檢查我的答案」時是術語和你的答案。
• 把來源標為敏感後，其內容只會傳給本機模型，絕不傳給遠端模型。看起來是私密的頁面（私有的 GitHub 儲存庫、未發布的 Notion 或 Google 文件頁面），在你選擇「僅用本機模型」或「照常傳送」之前，不會傳給任何模型。
• 無痕視窗只解釋，不記錄。
• 在 YouTube 上，Harkback 只讀取播放器正在顯示的字幕，而且只有在你新增該網站之後才會讀取。
• Harkback 本身只會下載選用的 OCR 語言資料，只下載一次，並用檢查碼核對。如果你選擇 Chrome 內建模型，點擊「下載」時由 Chrome 下載該模型。
• 沒有統計分析、廣告或追蹤。以 Apache-2.0 授權開源。
• API key 未加密保存在擴充功能儲存空間中，建議使用有額度限制的 key。

語言
介面支援十種語言，解釋可以用 16 種語言撰寫。
