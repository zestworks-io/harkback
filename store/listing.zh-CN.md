# Chrome 应用商店详情：简体中文

**名称：** Harkback

**摘要**（不超过 132 个字符）：
阅读时解释术语，记住你理解了什么，再次遇到时自动想起。记录保存在本机，使用你自己的模型。

**类别：** 工作效率

**语言：** 中文（简体）

## 详细说明

Harkback 适合阅读论文和技术文档的人。选中一个术语，它会结合你正在读的段落解释这个术语。每条解释都保存在你的浏览器里。之后在别的页面再遇到同一个术语，即使写法不同，Harkback 也会加下划线，并显示你上次的理解。

它不想成为一个更好的聊天机器人，而是补上聊天窗口缺少的东西：记忆。

使用方式
• 选中术语，点击「解释」或按 Alt+E。解释会结合术语所在的段落和章节；原文给出定义时，会引用原文。
• 把解释标为「懂了」或「还是不懂」。Harkback 会记住，并把你没把握的术语安排进复习。
• 在之后的页面上，你查过的术语会加下划线。悬停即可看到之前的解释、在哪里遇到过、当时理解得如何。缩写和全称互相匹配（“LLM”与“Large Language Model”）。
• 在任何卡片上继续追问，对话会和解释一起保存。
• 你的记录构成一张知识图谱：概念、别名、前置概念、变体和相关术语。可以搜索、复习，也可以导出为 Markdown 笔记（带 [[链接]]，适用于 Obsidian）或 JSONL 备份。

PDF 与论文
arXiv 论文自动可用。其他 PDF 会在 Harkback 自带的阅读器中打开，公式会排版。其他网站只有在你点击工具栏按钮或允许该网站时才会扫描。

模型由你选择
Harkback 没有服务器，也不需要账号。你连接自己的模型：可以是在你电脑上运行的模型（文字不会离开你的电脑），也可以是你用自己的 API key 使用的云端服务。

隐私
• 你的记录保存在浏览器里，开发者不会收到任何数据。
• 只发送你触发的请求：选中的文字、所在段落、章节和页面标题，发送给你配置的模型。
• 把来源标为敏感后，其内容只会发给本机模型，绝不发给远程模型。
• 无痕窗口只解释，不记录。
• 没有统计分析、广告或跟踪。以 Apache-2.0 协议开源。
• API key 未加密保存在扩展存储中，建议使用有额度限制的 key。

语言
界面支持九种语言，解释可以用 16 种语言书写。
