# Chrome 应用商店详情：简体中文

**名称：** Harkback

**摘要**（不超过 132 个字符）：
阅读时解释术语，记住你理解了什么，再次遇到时自动想起。记录保存在本机，使用你自己的模型。

**类别：** 工作效率

**语言：** 中文（简体）

## 详细说明

Harkback 适合阅读论文和技术文档的人。选中一个术语，它会结合你正在读的段落解释这个术语。每条解释都保存在你的浏览器里。之后在别的页面再遇到同一个术语，即使写法不同，Harkback 也会加下划线，并显示你上次的理解。

它不想成为一个更好的聊天机器人，而是补上聊天窗口缺少的东西：记忆。

使用方式
• 选中术语，点击「解释」、使用右键菜单，或按 Alt+Shift+E。解释会结合术语所在的段落和章节；原文给出定义时，会引用原文。
• 复习你没把握的术语。Harkback 用 FSRS-7 记忆模型安排复习：给自己选「重来」「困难」「良好」或「简单」，每个术语会在你快要忘记之前回来。互相依赖的术语会按正确的顺序复习，没弄懂的术语会指出你可能缺少的前置概念。
• 读之前先预览一页：看看其中哪些关键术语对你是新的，哪些你已经懂了。
• 在之后的页面上，你查过的术语会加下划线。悬停即可看到之前的解释、在哪里遇到过、当时理解得如何。缩写和全称互相匹配（“LLM”与“Large Language Model”）。
• 在任何卡片上继续追问，对话会和解释一起保存。可以中途停止回答，模型出错时也可以换一个模型重试。
• 你的记录构成一张知识图谱：概念、别名、前置概念、变体和相关术语。可以搜索、复习、以地图形式查看，也可以导出为 Markdown 笔记（带 [[链接]]，适用于 Obsidian）、Anki 卡片，或可再次导入的 JSONL 备份。

PDF 与论文
arXiv 论文自动可用。其他 PDF 会在 Harkback 自带的阅读器中打开，公式会排版。扫描版 PDF 在你滚动时用本机 OCR 识别，之后和普通文字一样使用。内置英文，其他语言从列表中下载一次即可。其他网站只有在你点击工具栏按钮或允许该网站时才会扫描。在「设置 → 网站」中还可以添加 GitHub（README、issue 和 pull request）、Notion、Google 文档（已发布或移动版视图）和 YouTube 字幕，也可以一键添加 bioRxiv、PubMed、OpenReview 等常用研究网站。

模型由你选择
Harkback 没有服务器，也不需要账号。你连接自己的模型：可以是在你电脑上运行的模型（文字不会离开你的电脑），也可以是你用自己的 API key 使用的云端服务。你自己局域网内的模型也可以。Chrome 内置模型（Gemini Nano）在你的电脑上运行，无需任何设置。它是小模型，比云端模型慢，适合简短的解释。

隐私
• 你的记录保存在浏览器里，开发者不会收到任何数据。
• 只会把你触发的内容发送给你配置的模型：解释时是选中的文字、所在段落、章节和页面标题；预览页面时是页面文字；「检查我的答案」时是术语和你的答案。
• 把来源标为敏感后，其内容只会发给本机模型，绝不发给远程模型。看起来是私密的页面（私有的 GitHub 仓库、未发布的 Notion 或 Google 文档页面），在你选择「仅本机」或「仍然发送」之前，不会发给任何模型。
• 无痕窗口只解释，不记录。
• 在 YouTube 上，Harkback 只读取播放器正在显示的字幕，而且只有在你添加该网站之后才会读取。
• Harkback 自身只会下载可选的 OCR 语言数据，只下载一次，并用校验和核对。如果你选择 Chrome 内置模型，点击「下载」时由 Chrome 下载该模型。
• 没有统计分析、广告或跟踪。以 Apache-2.0 协议开源。
• API key 未加密保存在扩展存储中，建议使用有额度限制的 key。

语言
界面支持九种语言，解释可以用 16 种语言书写。
