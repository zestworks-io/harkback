# Chrome ウェブストアの掲載情報：日本語

**名前：** Harkback

**概要**（132 文字以内）：
読みながら用語を解説し、理解した内容を覚えておき、同じ用語に再び出会ったときに思い出させます。記録は手元に保存され、モデルは自分で選べます。

**カテゴリ：** 仕事効率化

**言語：** 日本語

## 詳細な説明

Harkback は、論文や技術文書を読む人のための拡張機能です。用語を選択すると、読んでいる段落の文脈に沿ってその用語を解説します。解説はすべてブラウザー内に保存されます。のちに別のページで同じ用語に出会うと（表記が違っていても）、Harkback は下線を引き、前回どう理解したかを表示します。

より優れたチャットボットを目指すものではありません。チャット画面に足りないもの、つまり記憶を補います。

使い方
• 用語を選択し、「解説」をクリックするか、右クリックメニューを使うか、Alt+Shift+E を押します。解説は用語の周りの段落とセクションを踏まえ、ページが定義している場合はその文を引用します。
• 自信のない用語を復習します。Harkback は FSRS-7 記憶モデルで復習を予定します。「もう一度」「難しい」「できた」「簡単」で自己評価すると、各用語は忘れる少し前に戻ってきます。他の用語を土台にする用語は正しい順序で復習され、混乱している用語には、足りないかもしれない前提知識が示されます。
• 読む前にページを下見：重要な用語のうち、初めてのものと既に知っているものが分かります。
• 以降のページでは、調べたことのある用語に下線が引かれます。ポイントすると、以前の解説、出会った場所、どのくらい理解したかが表示されます。略語は正式名称と照合されます（「LLM」と「Large Language Model」）。
• どのカードでも追加で質問できます。会話は解説と一緒に保存されます。回答を途中で止めたり、失敗したら別のモデルで再試行したりできます。
• 記録は、概念、別名、前提、派生形、関連用語からなる知識グラフになります。検索や復習ができ、マップとして眺めることも、Markdown ノート（Obsidian 向けの [[リンク]] 付き）、Anki カード、再び取り込める JSONL バックアップとして書き出すこともできます。

PDF と論文
arXiv の論文は自動で使えます。そのほかの PDF は Harkback 独自のリーダーで開き、数式が組版されます。スキャンされた PDF は、スクロールに合わせてコンピューター上で OCR により読み取られ、その後は通常のテキストのように扱えます。英語は内蔵で、そのほかの言語は一覧から一度だけダウンロードします。ほかのウェブサイトは、ツールバーのボタンをクリックするか、サイトを許可したときだけスキャンされます。「設定 → サイト」では、GitHub（README、issue、pull request）、Notion、Google ドキュメント（公開ビューまたはモバイルビュー）、YouTube の字幕を追加でき、bioRxiv、PubMed、OpenReview などの代表的な研究サイトもボタン 1 つで追加できます。

モデルは自分で選ぶ
Harkback にはサーバーもアカウントもありません。ご自身のモデルを接続します。コンピューター上で動くモデル（テキストはコンピューターの外に出ません）か、自分の API キーで使うホスト型サービスです。自宅などのネットワーク内のモデルも使えます。Chrome 内蔵モデル（Gemini Nano）は、設定なしでコンピューター上で動作します。小さなモデルなのでクラウドのモデルより遅く、短い解説に向いています。

プライバシー
• 記録はブラウザー内に残ります。開発者には何も届きません。
• 設定したモデルに送られるのは、あなたが操作した内容だけです。解説では選択したテキスト、その段落、セクション、ページのタイトル。ページの下見ではページのテキスト。「回答を確認」では用語とあなたの回答です。
• 情報源を機密にすると、その内容はローカルモデルにだけ送られ、リモートモデルには決して送られません。非公開に見えるページ（非公開の GitHub リポジトリ、未公開の Notion や Google ドキュメントのページ）は、「ローカルのみ」または「そのまま送信」を選ぶまで、どのモデルにも送られません。
• プライベートウィンドウでは解説のみで、何も記録しません。
• YouTube では、プレーヤーが表示している字幕だけを読み、サイトを追加した後に限ります。
• Harkback 自身がダウンロードするのは、任意の OCR 言語データだけで、1 回限り、チェックサムで検証します。Chrome 内蔵モデルを選んだ場合、「ダウンロード」をクリックすると Chrome がそのモデルをダウンロードします。
• 分析、広告、トラッキングはありません。Apache-2.0 のオープンソースです。
• API キーは拡張機能のストレージに暗号化せずに保存されます。利用上限のあるキーをお勧めします。

言語
インターフェースは 10 の言語で利用でき、解説は 16 の言語で書けます。
