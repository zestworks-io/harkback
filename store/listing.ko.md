# Chrome 웹 스토어 등록 정보: 한국어

**이름:** Harkback

**요약** (132자 이내):
읽으면서 용어를 설명하고, 이해한 내용을 기억해 두었다가, 같은 용어를 다시 만나면 떠올려 줍니다. 기록은 내 기기에 저장되고 모델은 직접 고릅니다.

**카테고리:** 생산성

**언어:** 한국어

## 자세한 설명

Harkback은 논문과 기술 문서를 읽는 사람을 위한 확장 프로그램입니다. 용어를 선택하면 읽고 있는 문단의 맥락에 맞춰 그 용어를 설명합니다. 모든 설명은 브라우저에 저장됩니다. 나중에 다른 페이지에서 같은 용어를 만나면(표기가 달라도) Harkback이 밑줄을 긋고 지난번에 어떻게 이해했는지 보여 줍니다.

더 나은 챗봇이 되려는 것이 아닙니다. 채팅 창에 없는 것, 바로 기억을 더해 줍니다.

사용 방법
• 용어를 선택한 뒤 「설명」을 클릭하거나 오른쪽 클릭 메뉴를 쓰거나 Alt+Shift+E를 누릅니다. 설명은 용어 주변의 문단과 섹션을 활용하며, 페이지가 용어를 정의하고 있으면 그 문장을 인용합니다.
• 확신이 없는 용어를 복습합니다. Harkback은 FSRS-7 기억 모델로 복습을 예약합니다. 「다시」, 「어려움」, 「좋음」, 「쉬움」으로 스스로 평가하면 각 용어가 잊어버리기 직전에 돌아옵니다. 다른 용어를 바탕으로 하는 용어는 올바른 순서로 복습되고, 헷갈리는 용어는 부족할 수 있는 선행 개념을 알려 줍니다. 도구 모음 아이콘을 오른쪽 클릭하면 「복습」이나 「기록」을 열 수 있습니다.
• 읽기 전에 페이지를 미리 보기: 핵심 용어 중 처음 보는 것과 이미 아는 것이 무엇인지 확인합니다.
• 이후의 페이지에서는 찾아본 적이 있는 용어에 밑줄이 그어집니다. 마우스를 올리면 이전 설명, 만난 곳, 이해한 정도를 볼 수 있습니다. 약어는 정식 명칭과 연결됩니다(「LLM」과 「Large Language Model」).
• 어느 카드에서든 추가로 질문할 수 있습니다. 대화는 설명과 함께 저장됩니다. 답변을 도중에 멈추거나, 실패하면 다른 모델로 다시 시도할 수 있습니다.
• 기록은 개념, 별칭, 선행 개념, 변형, 관련 용어로 이루어진 지식 그래프가 됩니다. 모델이 확신하지 못한 관계는 직접 확인하고, 서로 다른 두 용어가 하나로 합쳐진 개념은 분리할 수 있습니다(병합을 되돌릴 때도 씁니다). 검색하고 복습하고 지도처럼 볼 수 있으며, Markdown 노트(Obsidian용 [[링크]] 포함), Anki 카드, 다시 가져올 수 있는 JSONL 백업으로 내보낼 수도 있습니다.
• 데이터 공유지에 기여: 공개 라이선스가 있는 arXiv·DOI 논문에서 찾아본 기록(논문 ID, 용어, 분야, 이해 정도, 월)으로 Harkback이 익명 파일을 만들고, 전체 내용을 보여 준 뒤 컴퓨터에 저장합니다.

PDF와 논문
arXiv 논문은 자동으로 작동합니다. 다른 PDF는 Harkback 자체 리더에서 열리고 수식이 조판됩니다. 스캔한 PDF는 스크롤하는 동안 컴퓨터에서 OCR로 읽어 이후 일반 텍스트처럼 쓸 수 있습니다. 영어는 내장되어 있고 다른 언어는 목록에서 한 번만 내려받습니다. 다른 웹사이트는 도구 모음 버튼을 클릭하거나 사이트를 허용했을 때만 스캔됩니다. 「설정 → 사이트」에서 GitHub(README, issue, pull request), Notion, Google 문서(게시 보기 또는 모바일 보기), YouTube 자막을 추가할 수 있고, bioRxiv, PubMed, OpenReview 같은 대표적인 연구 사이트도 버튼 한 번으로 추가할 수 있습니다. YouTube 자동 자막에서는 음성 인식이 용어를 소문자로 적거나, 한 글자씩 끊어 적거나, 조금 잘못 알아들어도 용어를 알아봅니다.

모델은 직접 선택
Harkback에는 서버도 계정도 없습니다. 내 모델을 연결합니다. 컴퓨터에서 실행되는 모델(텍스트가 컴퓨터 밖으로 나가지 않음)이거나, 내 API 키로 쓰는 호스팅 서비스입니다. 같은 네트워크 안의 모델도 쓸 수 있습니다. Chrome 내장 모델(Gemini Nano)은 설정 없이 컴퓨터에서 실행됩니다. 작은 모델이라 클라우드 모델보다 느리며 짧은 설명에 적합합니다.

개인정보 보호
• 기록은 브라우저에 남습니다. 개발자는 아무것도 받지 않습니다.
• 설정한 모델에는 사용자가 실행한 내용만 전송됩니다. 설명에는 선택한 텍스트, 그 문단, 섹션, 페이지 제목이, 페이지 미리 보기에는 페이지 텍스트가, 「내 답변 확인」에는 용어와 내 답변이 전송됩니다.
• 출처를 민감으로 표시하면 그 내용은 로컬 모델에만 전송되며 원격 모델에는 절대 전송되지 않습니다. 비공개로 보이는 페이지(비공개 GitHub 저장소, 게시되지 않은 Notion 또는 Google 문서 페이지)는 「로컬만」 또는 「그대로 보내기」를 고르기 전까지 어떤 모델에도 전송되지 않습니다.
• 비공개 창에서는 설명만 하고 아무것도 기록하지 않습니다.
• YouTube에서는 플레이어가 표시 중인 자막만 읽으며, 사이트를 추가한 뒤에만 읽습니다.
• 데이터 공유지용 파일에는 인용문, 설명, 주소, 정확한 시각이 없으며, 민감한 출처는 절대 포함되지 않습니다. 아무것도 업로드되지 않으며, 어딘가에 제출할지는 직접 정합니다.
• Harkback 자체가 내려받는 것은 선택적인 OCR 언어 데이터뿐이며, 한 번만 내려받고 체크섬으로 확인합니다. Chrome 내장 모델을 선택하면 「다운로드」를 클릭할 때 Chrome이 그 모델을 내려받습니다.
• 분석, 광고, 추적이 없습니다. Apache-2.0 오픈 소스입니다.
• API 키는 확장 프로그램 저장소에 암호화되지 않은 채 저장됩니다. 사용 한도가 있는 키를 권장합니다.
