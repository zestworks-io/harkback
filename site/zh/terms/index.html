使用条款

最后更新：2026 年 10 月 1 日

本条款适用于 Harkback 浏览器扩展及本网站。安装或使用 Harkback 即表示你同意本条款；如不同意，请不要使用。

1. 软件

Harkback 是依据 Apache License 2.0 发布的开源软件。该许可证规定你复制、修改和再分发代码的权利；本条款规定你对扩展本身的使用。

2. 你的模型服务与 API key

  • Harkback 使用你选择并配置的模型服务，并把你请求的文字发送给该服务。你对它的使用受该服务商的条款、隐私政策和定价约束，与 Zestworks 无关。
  • 你需要自行保管 API key，承担服务商收取的任何费用，并确保你有权把所选文字发送给你选择的服务商。key 在浏览器中未加密保存（见隐私政策），建议使用有额度限制的 key。
  • Zestworks 不运营任何模型服务，也不会接收你的请求、文字或 key。

3. AI 输出可能有误

解释由语言模型生成，可能不准确、不完整或已过时。重要内容请对照原文核实。Harkback 是阅读辅助工具，不构成专业、法律、医疗或财务建议。

4. 你的内容与数据

你对所阅读的文档和你创建的记录保留全部权利。记录保存在你自己的设备上，请自行备份。Harkback 每周会把备份文件保存到下载文件夹，但无法保证数据永不丢失。

5. 可接受的使用

  • 只对你有权阅读、并有权发送给所选模型服务的内容使用 Harkback。保密来源请标为敏感，并使用本机模型。
  • 不得用它违反法律、侵犯他人权利，或绕过网站的访问控制或模型服务商的条款。
  • 不得干扰本网站，或把修改过的扩展冒充为官方版本。

6. 不提供担保

在法律允许的范围内，Harkback 按“现状”和“可用状态”提供，不附带任何明示或暗示的担保，包括适用于特定用途、准确性和不侵权的担保。

7. 责任限制

在法律允许的范围内，Zestworks 及贡献者不对间接、附带或后果性损失、数据或利润损失，或第三方模型服务商收取的费用承担责任。本条款不限制依法不能限制的责任。

8. 变更与终止

我们可能更新本条款，并在更新时修改上方日期。变更后继续使用即表示你接受变更。你可以随时通过卸载扩展停止使用。我们可能停止维护 Harkback 或本网站。

如有疑问，请在 github.com/zestworks-io/harkback/issues 提交 issue。
