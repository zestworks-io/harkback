隐私政策

最后更新：2026 年 10 月 20 日

Harkback 是一个浏览器扩展：阅读时解释术语，并记住你理解了什么。它没有自己的服务器，开发者不会接收、存储或看到你的任何数据。

Harkback 保存什么

  • 你的记录（解释、追问、笔记、“懂了 / 还没懂”标记以及它们的来源；页面注明了许可的，还包括来源的许可）保存在你的浏览器中，即扩展的本地存储。它们不会发送给开发者。
  • 你的设置，包括你填写的模型 API key 和 Zotero API key，保存在浏览器的扩展存储中。key 未加密。模型 key 只会发送到你填写的模型地址，Zotero key 只会发送到 api.zotero.org。
  • 备份。Harkback 每周把一份包含你记录的 JSONL 文件保存到你电脑的 下载/harkback 文件夹。备份只含记录，不含设置或 API key。你也可以在历史页自行导出数据。
  • 贡献文件（可选）。如果你在历史页选择贡献，Harkback 会用你在开放许可的 arXiv 和 DOI 论文中的查词记录生成一个匿名文件：论文编号、许可、术语、所属领域和章节、你的理解程度和月份，以及你确认过的关系。文件不含引文、解释、网址或确切时间，也绝不包含敏感来源。保存到电脑之前，你能看到文件的全部内容。不会上传任何东西；是否提交、提交到哪里，由你决定。保存时会在你的记录中留下一条说明，写明你同意贡献的范围。

哪些内容会离开你的浏览器

只有你触发的请求。当你请求解释时，Harkback 会把选中的文字、所在段落、章节和页面标题发送给你配置的模型服务（例如云端 API 或 Ollama 这样的本机服务）。该服务按其自己的条款和隐私政策处理这些数据。你标为敏感的来源，其内容绝不会发给非本机模型。复习中可选的「检查我的回答」也是如此：只有你点击时，Harkback 才会把术语、你输入的回答和当时的解释发给你的模型。你可以在设置中关闭它。页面预览也是如此：只有你点击「扫描」时，Harkback 才会把页面文字（前 16,000 个字符）发给你的模型，你标为敏感的页面只会使用本机模型。Chrome 内置模型在你的电脑上运行，不会发送到任何地方；该模型由 Chrome 自己在你点击「下载模型」时下载。

扫描版 PDF 在你的电脑上识别文字，页面图像不会离开电脑。识别唯一可能发出的网络请求，是从 jsdelivr.net（cdn.jsdelivr.net；无法访问时改用 fastly.jsdelivr.net 和 gcore.jsdelivr.net）下载语言包（英文已内置），且只在你于「语言」中安装某种语言时下载一次。该请求不含任何文档内容，语言包在使用前会用随 Harkback 发布的校验值检查。

从 Zotero 导入（可选）。只有当你在「设置 → 数据与隐私 → Zotero」中点击查找划线时，Harkback 才会把你的 Zotero API key 发送到 api.zotero.org，读取你的划线以及它们所属的论文和文件。你保持勾选的简短划线会记为查词记录，附带论文标题及其 arXiv 编号或 DOI；不是已发表论文的文件会记为敏感来源。不会向你的 Zotero 文献库写入任何内容，你的记录也不会发送给 Zotero。

Harkback 不含统计分析、广告或跟踪，也不会出售或分享你的数据。

权限

  • 网站访问（可选）。只有当你选择扫描某个网站或把它加入允许列表时，Harkback 才会请求访问该网站；它还会请求访问你模型的地址，以便发送你的请求；从 Zotero 导入时，还会请求访问 api.zotero.org。在 arxiv.org 上会自动运行。
  • 本地文件（可选）。要读取电脑上的 PDF，你可以允许访问本地文件。文件只在浏览器中读取，不会上传。
  • 其他权限。storage 用于保存记录和设置；alarms 用于安排每周备份并刷新工具栏图标上的待复习数量；downloads 用于写入备份；offscreen 用于生成备份文件；scripting 和 activeTab 让工具栏按钮和快捷键可以读取你当前所在的页面；contextMenus 在选中文字的右键菜单中加入“Harkback: 解释”，在页面右键菜单中加入“Harkback: 预览本页概念”，并在工具栏图标的右键菜单中加入“复习”和“历史”。

无痕窗口

无痕窗口默认关闭。启用后，Harkback 只解释，不记录、不扫描、也不显示提醒。

删除你的数据

可在历史页删除记录，或卸载扩展以清除它在浏览器中保存的全部内容。删除一条记录会清除它的文字（引文、解释和追问）；术语名称以及来源的标题和地址会留在你的记录中，因为其他记录可能引用它们。已保存到你磁盘上的备份和导出文件，由你自行删除。

本政策的变更

如果 Harkback 处理数据的方式发生变化，会在变更发布前更新本页和上方日期。历史记录公开在代码仓库中。
