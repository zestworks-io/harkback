隐私政策

最后更新：2026 年 10 月 1 日

Harkback 是一个浏览器扩展：阅读时解释术语，并记住你理解了什么。它没有自己的服务器，开发者不会接收、存储或看到你的任何数据。

Harkback 保存什么

  • 你的记录（解释、追问、笔记、“懂了 / 还没懂”标记以及它们的来源）保存在你的浏览器中，即扩展的本地存储。它们不会发送给开发者。
  • 你的设置，包括你填写的模型 API key，保存在浏览器的扩展存储中。key 未加密，只会发送到你填写的模型地址。
  • 备份。Harkback 每周把一份包含你记录的 JSONL 文件保存到你电脑的 下载/harkback 文件夹。备份只含记录，不含设置或 API key。你也可以在历史页自行导出数据。

哪些内容会离开你的浏览器

只有你触发的请求。当你请求解释时，Harkback 会把选中的文字、所在段落、章节和页面标题发送给你配置的模型服务（例如云端 API 或 Ollama 这样的本机服务）。该服务按其自己的条款和隐私政策处理这些数据。你标为敏感的来源，其内容绝不会发给非本机模型。

扫描版 PDF 在你的电脑上识别文字，页面图像不会离开电脑。识别唯一可能发出的网络请求，是从 cdn.jsdelivr.net 下载语言包（英文已内置），且只在你于「语言」中安装某种语言时下载一次。该请求不含任何文档内容，语言包在使用前会用随 Harkback 发布的校验值检查。

Harkback 不含统计分析、广告或跟踪，也不会出售或分享你的数据。

权限

  • 网站访问（可选）。只有当你选择扫描某个网站或把它加入允许列表时，Harkback 才会请求访问该网站；它还会请求访问你模型的地址，以便发送你的请求。在 arxiv.org 上会自动运行。
  • 本地文件（可选）。要读取电脑上的 PDF，你可以允许访问本地文件。文件只在浏览器中读取，不会上传。
  • 其他权限。storage 用于保存记录和设置；alarms 用于安排每周备份并刷新工具栏图标上的待复习数量；downloads 用于写入备份；offscreen 用于生成备份文件；scripting 和 activeTab 让工具栏按钮可以读取你当前所在的页面；contextMenus 在选中文字的右键菜单中加入“用 Harkback 解释”。

无痕窗口

无痕窗口默认关闭。启用后，Harkback 只解释，不记录、不扫描、也不显示提醒。

删除你的数据

可在历史页删除记录，或卸载扩展以清除它在浏览器中保存的全部内容。已保存到你磁盘上的备份和导出文件，由你自行删除。

本政策的变更

如果 Harkback 处理数据的方式发生变化，会在变更发布前更新本页和上方日期。历史记录公开在代码仓库中。

联系方式

如有疑问，请在 github.com/zestworks-io/harkback/issues 提交 issue。
