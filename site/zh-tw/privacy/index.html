隱私權政策

最後更新：2026 年 10 月 9 日

這是翻譯版本；若與英文版本有出入，以英文版本為準。

Harkback 是一個瀏覽器擴充功能：閱讀時解釋術語，並記住你理解了什麼。它沒有自己的伺服器，開發者不會接收、儲存或看到你的任何資料。

Harkback 儲存什麼

  • 你的紀錄（解釋、追問、筆記、「懂了 / 還沒懂」標記以及它們的來源）保存在你的瀏覽器中，也就是擴充功能的本機儲存空間。它們不會傳送給開發者。
  • 你的設定，包括你填寫的模型 API 金鑰，保存在瀏覽器的擴充功能儲存空間中。金鑰未加密，只會傳送到你填寫的模型位址。
  • 備份。Harkback 每週把一份包含你紀錄的 JSONL 檔案存到你電腦的 Downloads/harkback 資料夾。備份只含紀錄，不含設定或 API 金鑰。你也可以在資料庫頁自行匯出資料。

哪些內容會離開你的瀏覽器

只有你觸發的請求。當你要求解釋時，Harkback 會把選取的文字、所在段落、章節和頁面標題傳送給你設定的模型服務（例如雲端 API 或 Ollama 這類本機服務）。該服務依其自身的條款和隱私權政策處理這些資料。你標為敏感的來源，其內容絕不會傳給非本機模型。複習中選用的「檢查我的回答」也是如此：只有你按下時，Harkback 才會把術語、你輸入的回答和當時的解釋傳給你的模型。你可以在設定中關閉它。頁面預覽也是如此：只有你按下「掃描」時，Harkback 才會把頁面文字（前 16,000 個字元）傳給你的模型，你標為敏感的頁面只會使用本機模型。Chrome 內建模型在你的電腦上執行，不會傳送到任何地方；該模型由 Chrome 自己在你按下「下載模型」時下載。

掃描版 PDF 在你的電腦上辨識文字，頁面影像不會離開電腦。辨識唯一可能發出的網路請求，是從 cdn.jsdelivr.net 下載語言包（英文已內建），且只在你於「語言」中安裝某種語言時下載一次。該請求不含任何文件內容，語言包在使用前會以隨 Harkback 發布的檢查碼驗證。

Harkback 不含分析、廣告或追蹤，也不會出售或分享你的資料。

權限

  • 網站存取（選用）。只有當你選擇掃描某個網站或將它加入允許清單時，Harkback 才會要求存取該網站；它還會要求存取你的模型位址，以便傳送你的請求。在 arxiv.org 上會自動執行。
  • 本機檔案（選用）。若要讀取電腦上的 PDF，你可以允許存取本機檔案。檔案只在瀏覽器中讀取，不會上傳。
  • 其他權限。storage 用於保存紀錄和設定；alarms 用於安排每週備份並更新工具列圖示上的待複習數量；downloads 用於寫入備份；offscreen 用於產生備份檔案；scripting 和 activeTab 讓工具列按鈕和快速鍵可以讀取你目前所在的頁面；contextMenus 在選取文字的右鍵選單中加入「用 Harkback 解釋」，並在頁面右鍵選單中加入「Harkback: 預覽本頁概念」。

無痕視窗

無痕視窗預設關閉。啟用後，Harkback 只解釋，不記錄、不掃描，也不顯示提醒。

刪除你的資料

可在資料庫頁刪除紀錄，或移除擴充功能以清除它在瀏覽器中保存的全部內容。已存到你磁碟上的備份和匯出檔案，由你自行刪除。

本政策的變更

如果 Harkback 處理資料的方式有所變更，會在變更發布前更新本頁和上方日期。歷史紀錄公開在程式碼儲存庫中。
