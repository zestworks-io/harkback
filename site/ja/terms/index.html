2. モデルサービスと API キー

  • Harkback は、あなたが選んで設定したモデルサービスと連携して動作し、リクエストのテキストをそのサービスに送信します。その利用は、Zestworks ではなく、提供元の規約、プライバシーポリシー、料金に従います。
  • API キーの管理、提供元が請求する料金、選択した提供元に選択テキストを送る権利の有無は、あなたの責任です。キーは暗号化されずにブラウザに保存されます（プライバシーポリシーを参照）。利用上限を設定したキーを使ってください。
  • Zestworks はモデルサービスを運営しておらず、あなたのリクエスト、テキスト、キーを受け取ることはありません。

3. AI の出力は誤っていることがあります

解説は言語モデルが生成します。不正確、不完全、または古い場合があります。重要なことは出典で確認してください。Harkback は読書の補助であり、専門的、法律的、医療的、金融的な助言ではありません。

4. コンテンツとデータ

読む文書と作成した記録に関するすべての権利は、あなたが保持します。記録はあなた自身の端末に保存され、バックアップはあなたの責任です。Harkback は週次のバックアップファイルをダウンロードフォルダーに保存しますが、データが失われないことを保証するものではありません。

5. 許容される使用

  • Harkback は、読む権利があり、選択したモデルサービスに送ってよいコンテンツにのみ使用してください。機密の出典は機密としてマークし、ローカルモデルを使ってください。

  • このウェブサイトを妨害したり、改変した拡張機能を公式のものと偽ったりしないでください。

法律が許す範囲で、Harkback は「現状有姿」かつ「提供可能な範囲」で提供され、特定目的への適合性、正確性、非侵害を含め、明示・黙示を問わず一切の保証はありません。

8. 変更と終了

本規約は更新されることがあり、その際は上の日付を変更します。変更後も使い続けた場合、変更に同意したものとみなされます。拡張機能を削除すればいつでも利用を終了できます。Harkback またはこのウェブサイトの保守を終了することがあります。
