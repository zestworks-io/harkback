プライバシーポリシー

最終更新：2026 年 10 月 9 日

これは翻訳です。英語版と異なる場合は、英語版が優先されます。

Harkback は、読みながら用語を解説し、理解した内容を記録するブラウザ拡張機能です。独自のサーバーはなく、開発者があなたのデータを受信・保存・閲覧することはありません。

Harkback が保存するもの

  • 記録（解説、追加の質問、メモ、「わかった / まだわからない」の印、およびそれらの出典）は、ブラウザ内の拡張機能のローカルストレージに保存されます。開発者に送信されることはありません。
  • 設定（入力したモデルの API キーを含む）は、ブラウザ内の拡張機能のストレージに保存されます。キーは暗号化されません。入力したモデルのアドレスにのみ送信されます。
  • バックアップ。Harkback は週に一度、記録を含む JSONL ファイルをコンピューターの Downloads/harkback に保存します。含まれるのは記録のみで、設定や API キーは含まれません。ライブラリページから自分でデータを書き出すこともできます。

ブラウザの外に出るもの

あなたが操作したリクエストだけです。解説を求めると、Harkback は選択したテキスト、その段落、セクション、ページのタイトルを、設定したモデルサービス（クラウドの API や Ollama などのローカルサーバー）に送信します。そのサービスは、独自の規約とプライバシーポリシーに従ってデータを扱います。機密としてマークした出典の内容が、ローカル以外のモデルに送られることはありません。復習の任意機能「回答をチェック」も同様で、ボタンを押したときだけ、用語、入力した回答、保存された解説がモデルに送られます。設定でオフにできます。ページのプレビューも同様で、「スキャン」を押したときだけ、ページのテキスト（先頭 16,000 文字）がモデルに送られ、機密としてマークしたページではローカルモデルだけが使われます。Chrome 内蔵モデルはお使いのコンピューター上で動作するため、何も送信されません。このモデルは「モデルをダウンロード」を押したときに Chrome 自身がダウンロードします。

スキャンされた PDF はお使いのコンピューター上で読み取られ、ページ画像が外に出ることはありません。OCR が行いうる唯一のネットワークリクエストは、cdn.jsdelivr.net から言語パックをダウンロードすることです（英語は組み込み済み）。「言語」で言語をインストールしたときに一度だけ行われます。このリクエストに文書の内容は含まれず、言語パックは使用前に Harkback に同梱されたチェックサムで検証されます。

Harkback には解析、広告、トラッキングは含まれておらず、データを販売・共有することもありません。

権限

  • サイトへのアクセス（任意）。Harkback がウェブサイトへのアクセスを求めるのは、そのサイトのスキャンを選んだとき、または許可リストに追加したときだけです。また、リクエストを送るためにモデルのアドレスへのアクセスも求めます。arxiv.org では自動的に動作します。
  • ローカルファイル（任意）。コンピューター上の PDF を読むには、ローカルファイルへのアクセスを許可できます。ファイルはブラウザ内で読み取られ、アップロードされることはありません。
  • その他の権限。storage は記録と設定の保存、alarms は週次バックアップの予約とツールバーアイコンの復習件数の更新、downloads はそのバックアップの書き込み、offscreen はバックアップファイルの作成、scripting と activeTab はツールバーのボタンとキーボードショートカットが今開いているページを読むため、contextMenus は選択したテキストの右クリックメニューに「Harkback で解説」を、ページの右クリックメニューに「Harkback: このページをプレビュー」を追加するために使います。

プライベートウィンドウ

プライベート（シークレット）ウィンドウはデフォルトでオフです。有効にすると、Harkback は解説のみ行い、記録、スキャン、リマインダーの表示は行いません。

データの削除

ライブラリページで記録を削除するか、拡張機能を削除すると、ブラウザ内に保存されたすべてが消去されます。すでにディスクに保存されたバックアップや書き出しファイルは、ご自身で削除してください。

本ポリシーの変更

Harkback のデータの扱いが変わる場合は、変更の公開前にこのページと上の日付を更新します。履歴はリポジトリで公開されています。
