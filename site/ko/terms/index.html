이용약관

최종 업데이트: 2026년 10월 1일

이 문서는 번역본입니다. 영어본과 다른 경우 영어본이 우선합니다.

이 약관은 Harkback 브라우저 확장 프로그램과 이 웹사이트에 적용됩니다. Harkback을 설치하거나 사용하면 이 약관에 동의한 것으로 봅니다. 동의하지 않으면 사용하지 마세요.

1. 소프트웨어

Harkback은 Apache License 2.0으로 배포되는 오픈 소스 소프트웨어입니다. 코드를 복사, 수정, 재배포할 권리는 이 라이선스에 따릅니다. 이 약관은 확장 프로그램 자체의 사용에 적용됩니다.

2. 모델 서비스와 API 키

  • Harkback은 사용자가 선택하고 설정한 모델 서비스와 함께 동작하며, 요청한 텍스트를 해당 서비스로 보냅니다. 그 사용은 Zestworks가 아니라 해당 제공업체의 약관, 개인정보 처리방침, 요금에 따릅니다.
  • API 키 관리, 제공업체가 부과하는 요금, 선택한 제공업체에 선택한 텍스트를 보낼 권리가 있는지 여부는 사용자의 책임입니다. 키는 암호화되지 않은 채 브라우저에 저장됩니다(개인정보 처리방침 참조). 사용 한도가 설정된 키를 사용하세요.
  • Zestworks는 모델 서비스를 운영하지 않으며 사용자의 요청, 텍스트, 키를 받지 않습니다.

3. AI 출력은 틀릴 수 있습니다

설명은 언어 모델이 생성합니다. 부정확하거나, 불완전하거나, 오래된 내용일 수 있습니다. 중요한 내용은 원문과 대조해 확인하세요. Harkback은 읽기 보조 도구이며 전문적, 법률적, 의료적, 금융적 조언이 아닙니다.

4. 콘텐츠와 데이터

읽는 문서와 만든 기록에 대한 모든 권리는 사용자에게 있습니다. 기록은 사용자의 기기에 저장되며, 백업은 사용자의 책임입니다. Harkback은 주간 백업 파일을 다운로드 폴더에 저장하지만, 데이터가 절대 손실되지 않는다고 보장할 수는 없습니다.

5. 허용되는 사용

  • 읽을 권리가 있고 선택한 모델 서비스로 보내도 되는 콘텐츠에만 Harkback을 사용하세요. 기밀 출처는 민감한 출처로 표시하고 로컬 모델을 사용하세요.
  • 법을 위반하거나, 타인의 권리를 침해하거나, 웹사이트의 접근 제어나 모델 제공업체의 약관을 우회하는 데 사용하지 마세요.
  • 이 웹사이트를 방해하거나, 수정한 확장 프로그램을 공식 버전인 것처럼 속이지 마세요.

6. 보증의 부인

법이 허용하는 범위에서 Harkback은 "있는 그대로", "제공 가능한 상태로" 제공되며, 특정 목적에의 적합성, 정확성, 비침해를 포함해 명시적이든 묵시적이든 어떠한 보증도 하지 않습니다.

7. 책임의 제한

법이 허용하는 범위에서 Zestworks와 기여자는 간접적, 부수적, 결과적 손해, 데이터나 이익의 손실, 제3자 모델 제공업체가 부과하는 요금에 대해 책임을 지지 않습니다. 이 약관은 법으로 제한할 수 없는 책임을 제한하지 않습니다.

8. 변경과 종료

이 약관은 업데이트될 수 있으며, 그 경우 위의 날짜를 변경합니다. 변경 후에도 계속 사용하면 변경에 동의한 것으로 봅니다. 확장 프로그램을 제거하면 언제든 사용을 중단할 수 있습니다. Harkback이나 이 웹사이트의 유지 관리를 중단할 수도 있습니다.

9. 문의
