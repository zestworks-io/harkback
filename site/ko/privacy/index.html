Harkback
홈문서개인정보이용약관

개인정보 처리방침

최종 업데이트: 2026년 10월 9일

이 문서는 번역본입니다. 영어본과 다른 경우 영어본이 우선합니다.

Harkback은 읽는 동안 용어를 설명하고 이해한 내용을 기억해 주는 브라우저 확장 프로그램입니다. 자체 서버가 없으며, 개발자는 사용자의 어떤 데이터도 받거나 저장하거나 볼 수 없습니다.

Harkback이 저장하는 것

  • 기록(설명, 추가 질문, 메모, "이해했어요 / 아직 헷갈려요" 표시, 그리고 그 출처)은 브라우저 안의 확장 프로그램 로컬 저장소에 저장됩니다. 개발자에게 전송되지 않습니다.
  • 설정(입력한 모델 API 키 포함)은 브라우저 안의 확장 프로그램 저장소에 저장됩니다. 키는 암호화되지 않으며, 입력한 모델 주소로만 전송됩니다.
  • 백업. Harkback은 일주일에 한 번 기록이 담긴 JSONL 파일을 컴퓨터의 Downloads/harkback에 저장합니다. 기록만 담기며 설정이나 API 키는 포함되지 않습니다. 라이브러리 페이지에서 직접 데이터를 내보낼 수도 있습니다.

브라우저 밖으로 나가는 것

사용자가 실행한 요청만 나갑니다. 설명을 요청하면 Harkback은 선택한 텍스트, 해당 문단, 절, 페이지 제목을 사용자가 설정한 모델 서비스(예: 클라우드 API 또는 Ollama 같은 로컬 서버)로 보냅니다. 해당 서비스는 자체 약관과 개인정보 처리방침에 따라 데이터를 처리합니다. 민감한 출처로 표시한 내용은 로컬이 아닌 모델로 전송되지 않습니다. 복습의 선택 기능인 "내 답변 확인"도 마찬가지로, 버튼을 눌렀을 때만 용어, 입력한 답변, 저장된 설명이 모델로 전송됩니다. 설정에서 끌 수 있습니다. 페이지 미리보기도 같아서, "스캔"을 눌렀을 때만 페이지 텍스트(처음 16,000자)가 모델로 전송되며, 민감한 페이지로 표시한 곳에서는 로컬 모델만 사용합니다. Chrome 내장 모델은 사용자의 컴퓨터에서 실행되므로 아무것도 전송되지 않습니다. 이 모델은 "모델 다운로드"를 눌렀을 때 Chrome이 직접 내려받습니다.

스캔된 PDF는 사용자의 컴퓨터에서 읽으며, 페이지 이미지는 컴퓨터 밖으로 나가지 않습니다. OCR이 보낼 수 있는 유일한 네트워크 요청은 cdn.jsdelivr.net에서 언어 팩을 내려받는 것으로(영어는 내장), "언어"에서 언어를 설치할 때 한 번만 실행됩니다. 이 요청에는 문서 내용이 담기지 않으며, 언어 팩은 사용하기 전에 Harkback에 포함된 체크섬으로 검증됩니다.

Harkback에는 분석, 광고, 추적이 없으며 사용자의 데이터를 판매하거나 공유하지 않습니다.

권한

  • 사이트 접근(선택). Harkback은 사용자가 웹사이트를 스캔하기로 하거나 허용 목록에 추가할 때만 해당 사이트에 대한 접근을 요청하며, 요청을 보낼 수 있도록 모델 주소에 대한 접근도 요청합니다. arxiv.org에서는 자동으로 동작합니다.
  • 로컬 파일(선택). 컴퓨터에 있는 PDF를 읽으려면 로컬 파일 접근을 허용할 수 있습니다. 파일은 브라우저 안에서만 읽으며 업로드되지 않습니다.
  • 기타 권한. storage는 기록과 설정을 저장하고, alarms는 주간 백업을 예약하고 도구 모음 아이콘의 복습 개수를 갱신하며, downloads는 그 백업을 기록하고, offscreen은 백업 파일을 만들고, scripting과 activeTab은 도구 모음 버튼과 키보드 단축키가 현재 페이지를 읽게 하며, contextMenus는 선택한 텍스트의 오른쪽 클릭 메뉴에 "Harkback으로 설명"을, 페이지의 오른쪽 클릭 메뉴에 "Harkback: 이 페이지 미리보기"를 추가합니다.

시크릿 창

시크릿 창은 기본적으로 꺼져 있습니다. 켜면 Harkback은 설명만 하고, 기록, 스캔, 알림 표시는 하지 않습니다.

데이터 삭제

라이브러리 페이지에서 기록을 삭제하거나, 확장 프로그램을 제거하면 브라우저에 저장된 모든 것이 지워집니다. 이미 디스크에 저장된 백업과 내보낸 파일은 직접 삭제해야 합니다.

방침의 변경

Harkback이 데이터를 다루는 방식이 바뀌면, 변경이 적용되기 전에 이 페이지와 위의 날짜를 업데이트합니다. 변경 이력은 저장소에 공개되어 있습니다.
