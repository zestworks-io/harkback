Harkback은 논문과 기술 문서를 읽는 사람을 위한 Chrome 확장 프로그램입니다. 용어를 선택하면 문맥에 맞게 그 용어를 설명해 줍니다. 모든 설명은 로컬의 추가 전용(append-only) 로그에 보관됩니다. 나중에 다른 페이지에서 같은 용어가 나오면, 표기가 달라도 Harkback이 밑줄을 긋고 지난번에 이해한 내용을 보여 줍니다.

> “harken back”: 이전 시점으로 돌아가다.

## 빠른 시작

```sh
git clone https://github.com/zestworks-io/harkback.git && cd harkback
pnpm install && pnpm --filter @harkback/extension build
```

`chrome://extensions`를 열고 **개발자 모드**를 켠 다음, **압축해제된 확장 프로그램을 로드합니다**를 선택해 `apps/extension/.output/chrome-mv3`를 지정합니다. 그런 다음 모델을 고릅니다.

<details open>
<summary><b>로컬 모델 (무료)</b></summary>

[Ollama](https://ollama.com)를 설치하고 모델을 내려받은 뒤, 온보딩 페이지에서 **Ollama**를 선택합니다. 「연결 테스트」를 누르면 확장 프로그램을 허용하는 명령어 한 줄이 나옵니다. 내용이 컴퓨터 밖으로 나가지 않습니다.

</details>

<details>
<summary><b>클라우드 모델 (본인의 API 키)</b></summary>

OpenAI, Anthropic, Google Gemini, xAI Grok, OpenRouter 또는 OpenAI 호환 사용자 지정 주소를 선택하고 키를 붙여 넣습니다. 요금은 제공업체가 직접 청구하며, 중간에 Harkback 서버는 없습니다.

</details>

그런 다음 아무 페이지에서나 용어를 선택하고 `Alt+Shift+E`를 누르세요. 자세한 내용은 [설치](#설치)와 [모델 연결](#모델-연결)을 참고하세요. 처음 사용하는 방법은 [시작하기 가이드](guide/ko/getting-started.md)에 정리되어 있습니다.

## 그냥 ChatGPT에 물어보면 안 되나요?

용어를 챗봇에 붙여 넣으면 좋은 답을 얻을 수 있습니다. Harkback은 더 나은 답을 내놓으려는 것이 아닙니다. 채팅창에 없는 것, 바로 **기억**을 더합니다. 찾아본 용어는 모두 페이지, 인용문, 날짜와 연결된 기록이 되고, 기록들은 서로 이어져 나만의 지식 그래프가 됩니다.

|                 | 챗봇에 물어보기                              | Harkback                                                                    |
| --------------- | -------------------------------------------- | --------------------------------------------------------------------------- |
| **문맥**        | 용어와 주변 글을 복사해 탭을 바꿔 붙여 넣기  | 페이지에서 용어를 선택하면 해당 문단과 절이 함께 전달되고, 인용문은 검증됨  |
| **다음번**      | 새 대화는 텅 비어 있거나, 물어본 걸 잊어버림 | 이후 페이지에서 용어에 밑줄이 그어지고, 지난번에 이해한 내용이 표시됨       |
| **구조**        | 대화 기록 더미                               | 별칭, 선행 개념, 변형, 관련 용어를 가진 개념                                |
| **기억 유지**   | 없음                                         | 기억 모델이 일정을 짜는 복습 대기열: 잊어버리기 직전에 각 용어가 돌아옴     |
| **내 기록**     | 제공업체 계정에 있음                         | 브라우저에 남음. Markdown, Obsidian 노트, JSONL로 내보내기 가능             |
| **모델과 비용** | 서비스 하나, 요금제 하나                     | 지원하는 모델 중 자유롭게 선택: 로컬 Ollama는 무료, 또는 본인의 API 키 사용 |

Harkback은 무료 오픈소스(Apache-2.0)이며, 서버도 구독도 없습니다. 설명을 쓸 모델은 필요합니다. 로컬 모델은 무료이고, 클라우드 모델은 제공업체가 본인 키로 청구합니다.

## 기능

- **문맥 속에서 설명.** 용어를 선택하고 「설명」을 클릭하거나 `Alt+Shift+E`를 누릅니다. 설정한 모델에서 답이 스트리밍으로 도착하며, 「원문 정의」(페이지가 그 용어를 정의하고 있고 인용문이 페이지 본문과 대조됨) 또는 「외부 지식」으로 표시됩니다.
- **기억.** 설명, 추가 질문, 「이해함／아직 헷갈림」 표시는 각각 이벤트로 IndexedDB에 저장됩니다. 직접 실행한 모델 요청 외에는 아무것도 브라우저 밖으로 나가지 않습니다.
- **추가 질문 대화.** 카드에서 더 물어볼 수 있습니다. 질문은 답 위에 그대로 남고, 대화는 설명과 함께 저장됩니다. 기록에서 전체를 볼 수 있고 검색에도 잡힙니다. 수식은 조판되어 표시됩니다.
- **재회.** 이후 페이지에서는 찾아본 용어에 밑줄이 그어집니다. 마우스를 올리면 그 용어를 언제 어디서 만났는지, 무엇을 이해했는지, 페이지의 어떤 글자가 일치했는지 알려 주는 한 줄이 나타나고, 거기서 기억남으로 표시하거나, 다시 설명받거나, 두 용법을 비교하거나, 알림을 끌 수 있습니다.
- **하나의 개념, 여러 표기.** `LLM`, `LLMs`, `the LLM`, `large language model`, `Large-Language Models`는 같은 개념입니다. `β-VAE`와 `beta-VAE`, `fine-tuning`과 합자 `ﬁne-tuning`도 마찬가지입니다. 비슷한 일치는 「3일 전에 찾아본 그 용어인가요?」라고 물어봅니다.
- **관련 용어.** 모델이 `QLoRA`가 `LoRA`의 변형이라고 하면, `QLoRA`만 언급하는 페이지에서도 `LoRA`에 대해 이해했던 내용을 떠올려 줍니다.
- **개념 페이지.** 기록에서 용어를 열면 얼마나 이해했는지, 무엇을 기반으로 하는지(선행 개념), 변형과 관련 용어, 그리고 만났던 모든 순간을 볼 수 있습니다. 별칭을 추가하고, 같은 개념 두 개를 합치고, 잘못된 관계를 지우고, 용어의 알림을 끌 수 있습니다.
- **복습.** 기록에는 기한이 된 용어 수가 붙은 「복습」 버튼이 있습니다. 각 용어는 기억 모델 [FSRS-7](https://github.com/open-spaced-repetition/fsrs4anki)로 일정이 잡힙니다. 답을 「다시」, 「어려움」, 「좋음」, 「쉬움」으로 평가하면 잊어버리기 직전에 용어가 돌아오므로, 쉬운 용어는 간격이 빠르게 벌어지고 어려운 용어는 금방 다시 나옵니다. 각 버튼에는 그 용어가 언제 돌아오는지 표시됩니다. 설명을 보기 전에 기억나는 내용을 입력할 수 있고, 선택 사항인 **내 답 확인** 버튼은 얼마나 가까웠는지 모델에게 물어봅니다(제안하는 것은 평가뿐이며 결정은 본인이 하고, 설정에서 끌 수 있습니다). 복습 전체를 키보드로 할 수 있습니다. `Space`로 설명 표시, `1`–`4`로 평가, `S`로 건너뛰기. 둘 다 기한이 되었을 때는 다른 용어를 기반으로 하는 용어가 선행 개념 뒤에 나오며, 어려워하는 용어에는 부족할 수 있는 선행 개념이 안내됩니다. 재회 힌트에서 기억남으로 표시하면 가벼운 복습으로 셉니다. 용어의 기한이 되었을 때 기억하고 있을 확률은 설정에서 고를 수 있습니다(기본값 90%). 도구 모음 아이콘에 기한이 된 수가 표시됩니다.
- **주간 요약.** 기록 →「요약」에서 한 주 동안 만난 것을 볼 수 있습니다. 새 용어와 다시 만난 용어, 답, 아직 헷갈리는 용어, 읽은 곳, 개념 사이의 새로운 연결. 내 기록으로 컴퓨터에서 만들어지며 모델을 호출하지 않습니다.
- **아는 것 위에 쌓기.** 찾아본 용어가 이미 이해한 용어와 가까우면 모델에게 그 사실이 전달되어, 처음부터 다시 설명하는 대신 차이점을 설명할 수 있습니다.
- **기본부터 프라이버시 중심.** 사이트를 추가하기 전까지 자동 스캔은 arxiv.org로 제한됩니다. 설정의 버튼 하나로 흔한 연구 사이트를 한꺼번에 추가할 수 있습니다. 민감한 사이트는 로컬 모델만 쓰도록 강제할 수 있고, 시크릿 창에서는 기록도 스캔도 하지 않습니다.
- **옮길 수 있는 기록.** 모든 것을 Markdown, Anki 카드, 링크된 노트 폴더(개념마다 파일 하나, `[[링크]]` 포함, Obsidian에서 바로 사용 가능하며 표시 줄 아래에 직접 쓴 내용은 다음 내보내기 후에도 유지됨), 또는 공개된 JSON 스키마가 있는 버전 관리 JSONL 이벤트 로그로 내보낼 수 있습니다. 매주 JSONL 백업이 `Downloads/harkback`에 저장되며, 기록의 **JSONL 가져오기**로 복원합니다(이미 있는 기록은 건너뜀). 설정으로 민감한 출처를 백업과 내보내기에서 뺄 수 있습니다.
- **중지, 재시도, 모델 전환.** 「중지」 버튼으로 답을 쓰는 도중에 끝낼 수 있습니다. 실패하면 카드에 「다시 시도」가 나오고, 모델을 여러 개 설정했다면 다른 모델마다 「…로 시도」도 나옵니다.
- **읽기 전에 페이지 미리보기.** 도구 모음 버튼을 클릭하거나 `Alt+Shift+P`를 누르거나 오른쪽 클릭 메뉴를 사용하면, Harkback이 페이지 스캔을 제안하면서 사용할 모델과 원격 여부를 알려 줍니다. 동의하기 전에는 아무것도 전송되지 않습니다. 모델 호출 한 번으로 페이지의 핵심 용어를 고르고, 내 기록이 이를 「아직 헷갈림」, 「가물가물」, 「처음 보는 용어」, 「아는 용어」로 분류합니다. 「미리보기」는 아는 용어에는 이전 설명을, 새 용어에는 모델이 쓴 짧은 설명을 보여 주며 아무것도 기록하지 않습니다. 모델은 페이지 본문만 보고 내 개념 목록은 보지 못하며, 민감한 페이지는 로컬 모델만 사용합니다. 스캔은 페이지의 처음 16,000자를 읽고, 더 긴 페이지가 잘리면 알려 줍니다.
- **YouTube 자막.** 설정에서 YouTube를 추가하고 자막을 켜면, 전에 찾아본 용어가 자막 줄에서 밑줄로 표시됩니다. 일시정지하고 용어를 선택하면 지금까지 본 자막을 바탕으로 설명합니다. 찾아본 내용은 재생 위치(`12:34`)와 함께 기록되고, 기록·복습·내보내기에서 그 순간으로 돌아갈 수 있습니다. 사이트를 추가하기 전에는 꺼져 있습니다. 아무것도 다운로드하지 않으며 화면에 보이는 자막 줄만 읽습니다.
- **GitHub, Notion, Google 문서.** 설정에서 사이트를 추가하면 그 페이지는 각 사이트의 고유한 레이아웃대로 읽힙니다. 저장소의 README, 이슈나 풀 리퀘스트의 대화, Notion 페이지, Google 문서의 게시된 보기 또는 모바일 보기. 어떤 경로로 열었든 문서 하나는 하나의 출처로 취급하고, 문서 본문만 읽으며 주변 메뉴는 읽지 않습니다.
- **비공개 페이지는 보내기 전에 확인.** 비공개로 보이는 페이지(비공개 GitHub 저장소, 게시되지 않은 Notion이나 Google 문서 페이지 등)는 「로컬만」이나 「그대로 보내기」를 선택하기 전까지 어떤 모델에도 전송되지 않습니다. 페이지 모서리의 자물쇠가 상태를 보여 주고 바꿀 수 있으며, 선택은 기록되고 해당 사이트에 대해 기억하도록 할 수 있습니다.
- **다양한 시작 방법.** 텍스트를 선택하고 「설명」을 클릭하거나(마우스, 키보드, 터치 선택 모두 가능), `Alt+Shift+E`를 누르거나, 오른쪽 클릭 메뉴의 「설명」을 사용합니다. 텍스트를 더 불러오거나 새로 고침 없이 다른 페이지로 이동하는 페이지는 다시 스캔됩니다.
- **모델은 직접 선택.** Chrome 내장 Gemini Nano(내 컴퓨터에서 실행, 설정 불필요), Ollama, OpenAI, Anthropic, Google Gemini, xAI Grok, OpenRouter 또는 OpenAI 호환 서버. Anthropic과 Gemini는 고유 API를 사용합니다.

## 나만의 지식 그래프

찾아볼 때마다 읽은 내용의 그래프가 늘어납니다. 이 그래프는 범용 모델의 기억이 아니라 내가 직접 읽은 것으로 만들어집니다.

- **개념이 노드입니다.** `LoRA`는 페이지가 어떤 표기(`LoRA`, `low-rank adaptation`)를 쓰든, 어떤 언어로 만났든 하나의 노드입니다. 별칭, 분야, 이해도를 갖고 있습니다.
- **관계가 엣지입니다.** 용어를 찾아보면 모델이 `variant_of`, `prerequisite`, `related` 링크를 제안합니다. 예를 들어 `QLoRA`는 `LoRA`의 변형입니다. 잘못된 것은 지우고, 같은 개념 둘은 합치고, 별칭을 추가할 수 있습니다.
- **모든 것이 근거로 이어집니다.** 개념에는 만났던 모든 순간이 나열됩니다. 페이지, 인용문, 날짜, 내가 이해한 설명, 추가 질문 대화.
- **그래프가 일을 합니다.** `QLoRA`만 언급하는 페이지가 `LoRA`를 떠올리게 하고, 모델은 내가 이미 아는 것을 전달받아 차이를 설명할 수 있으며, 복습은 개념 단위로 일정이 잡힙니다.
- **내 것입니다.** 링크된 노트 폴더(`[[링크]]`, 개념마다 파일 하나)를 내보내 Obsidian에서 열면 그래프를 볼 수 있고, 전체 이벤트 로그를 JSONL로 내보낼 수도 있습니다.

기록의 **그래프**를 열면 지도로 볼 수 있습니다. 개념은 이해도(이해함, 불안함, 헷갈림, 새로움)에 따라 색이 입혀지고, 화살표는 선행 개념과 변형을 나타냅니다. 분야, 이해도, 마지막으로 찾아본 시점으로 거를 수 있습니다. 끌어서 이동하고, 스크롤로 확대·축소하고, 개념을 클릭해 엽니다. 개념 페이지나, 내보낸 뒤 Obsidian으로도 둘러볼 수 있습니다.

## 작동 방식

```
 읽기                설명                    기억                     회상
 ────                ───────                 ────────                 ──────
 content script  →   background worker   →   추가 전용 이벤트 로그  →  매처가 다음 페이지에서
 페이지 텍스트를     사이트 민감도에 따라    (IndexedDB), 재생하면     알려진 이름을 찾고, 보여 줄
 추출하고 선택을     모델로 라우팅하고,      개념·별칭·만남이 됨       가치가 있는 개념을 골라
 추적                답을 스트리밍하고,                                밑줄과 카드를 그림
                     개념을 확정
```

1. **읽기.** content script가 페이지의 읽을 수 있는 텍스트를 추출하고(arXiv에서는 LaTeXML 구조, 그 밖에는 Readability), 텍스트 오프셋에서 DOM 노드로 돌아가는 대응표를 유지합니다.
2. **설명.** background worker가 사이트 규칙을 확인하고, 모델을 고르고, 로컬 속도 제한을 적용한 뒤, 용어를 그 문단과 함께 보냅니다. 프롬프트에는 알려진 개념이 후보로 나열되어, 모델이 「이것은 c1과 같은 개념」이라고 답할 수 있습니다. 응답 파싱은 관대합니다. 잘린 카드, 끝의 쉼표, 장식이 붙은 라벨도 허용합니다.
3. **기억.** 결과는 이벤트(`concept.created`, `encounter.created`, `edge.proposed` 등)가 됩니다. 개념, 별칭, 병합은 로그를 재생해서 도출하며 따로 저장하지 않으므로, 더 나은 매칭 규칙이 과거 기록도 개선합니다.
4. **회상.** 페이지마다 Aho-Corasick 매처가 텍스트에서 알려진 모든 이름과 약어를 찾습니다. 이어서 재회 선택이 쓸모를 유지하는 규칙을 적용합니다. 용어를 찾아본 그 페이지에서는 보이지 않고, 최소 간격 안에서는 보이지 않으며, 알림을 끈 개념은 계속 꺼져 있고, 모호한 약어는 페이지에 같은 분야의 두 번째 용어가 있어야 합니다.

## 설치

Node 22 이상과 [pnpm](https://pnpm.io)이 필요합니다. 아직 스토어에 등록되어 있지 않으므로 소스에서 확장 프로그램을 로드합니다.

```sh
# 저장소 루트에서
pnpm install
pnpm --filter @harkback/extension build
```

`chrome://extensions`를 열고 **개발자 모드**를 켠 다음, **압축해제된 확장 프로그램을 로드합니다**를 선택해 `apps/extension/.output/chrome-mv3`를 지정합니다. 설치하면 온보딩 페이지가 열립니다.

**Microsoft Edge.** `apps/extension`에서 `pnpm build -b edge`(또는 `pnpm zip:edge`)를 실행하고, `edge://extensions`를 열어 **개발자 모드**를 켠 다음, **압축 풀기 로드**를 선택해 `apps/extension/.output/edge-mv3`를 지정합니다. Edge에는 Chrome 내장 모델이 없을 수 있으니, 설정에서 다른 모델을 고르세요.

## 모델 연결

온보딩은 세 단계입니다. **시작**(재회 힌트 예시와, 모델을 호출하지 않고 체험할 수 있는 내장 설명 예시), **개인정보 보호**(텍스트가 어디로 가는지. 동의 체크박스를 선택해야 「다음」이 활성화됩니다), **모델**(제공업체를 고르고 「완료」). 온보딩을 다시 실행하면 복사본을 추가하지 않고 이미 있는 모델을 업데이트합니다. 모델 추가와 옵션 변경은 나중에 설정 페이지에서 할 수 있으며, 설정 페이지에서는 속도 제한, 재회 힌트, 모델이 응답하지 않을 때 요청을 포기하기까지의 시간도 정할 수 있습니다.

```sh
launchctl setenv OLLAMA_ORIGINS "chrome-extension://<your-extension-id>"
```

## 개인정보 보호

- 설명을 요청하면, 선택한 텍스트, 그 문단, 절, 페이지 제목이 설정한 모델 서비스로 해당 제공업체의 약관에 따라 전송됩니다.
- 복습에서 선택 사항인 **내 답 확인** 버튼은 누를 때에만 용어, 입력한 답, 저장된 설명을 내 모델에 보냅니다. 설정에서 끄면 버튼이 나타나지 않습니다. 설명과 같은 모델 및 민감한 출처 규칙을 따릅니다.
- 기록은 이 브라우저에 남습니다. 백업에는 기록만 들어 있으며 설정이나 API 키는 절대 들어 있지 않습니다.
- 페이지는 arxiv.org에서만 자동으로 스캔됩니다. 그 외의 곳에서는 버튼을 클릭하거나, `Alt+Shift+E`를 누르거나, 사이트를 허용해야 합니다.
- 민감한 출처의 내용은 이후 비교의 문맥으로도 로컬이 아닌 모델에 절대 전송되지 않습니다. 내 네트워크의 서버도 로컬이 아닌 것으로 취급합니다. 출처는 기록 항목에서 일반으로 되돌리기 전까지 민감한 상태로 유지됩니다.
- 비공개로 보이는 페이지(비공개 GitHub 저장소, 게시되지 않은 Notion이나 Google 문서 페이지)는 선택하기 전까지 어떤 모델에도 전송되지 않습니다. 사이트가 어느 쪽인지 표시하지 않은 페이지는 Notion과 Google 문서에서는 물어보고 GitHub에서는 묻지 않습니다. 페이지가 스스로에 대해 알려 주는 것은 힌트일 뿐이므로, 중요할 때는 사이트를 민감으로 표시하세요.
- 설정으로 민감한 출처를 백업과 내보내기에서 뺄 수 있습니다.
- 시크릿 창에서는 설명은 하지만 기록, 스캔, 재회 표시는 하지 않습니다.
- 재회 밑줄은 페이지 안에 있으므로, 페이지의 스크립트가 내가 어떤 용어의 기록을 갖고 있는지 추측할 수 있습니다.
- 설명을 삭제하면 앱에서는 지워지지만, 디스크에 흔적이 남을 수 있고 이미 내보낸 백업은 회수할 수 없습니다.
- API 키는 확장 프로그램 저장소에 **암호화되지 않은 채** 저장됩니다.

확장 프로그램에 표시되는 안내가 기준입니다: [`apps/extension/src/lib/pages/privacy.ts`](apps/extension/src/lib/pages/privacy.ts).

## 내 데이터

모든 것은 추가 전용 로그의 이벤트입니다. 형식은 공개되어 있습니다.

- 이벤트 유형과 페이로드: [`packages/spec`](packages/spec), 그리고 생성된 [JSON 스키마](packages/spec/schema/event.schema.json).
- 재생, 매칭, 내보내기: [`packages/core`](packages/core). 브라우저 의존성이 없어 단독으로 쓸 수 있습니다.

개념과 별칭은 로그에서 도출되므로, JSONL 백업은 내가 아는 것의 완전하고 이식 가능한 사본입니다.

## 제한 사항

- Chrome과 Microsoft Edge(Manifest V3). Firefox와 Safari는 지원하지 않습니다. Chrome 내장 모델은 모든 브라우저에서 쓸 수 있는 것은 아니며, Edge는 다른 모델이 필요합니다.
- 설명은 선택한 모델에 좌우됩니다. 작은 로컬 모델은 개념 카드가 약해질 수 있고, 이는 재회의 품질을 낮추지만 기록 자체를 망가뜨리지는 않습니다.
- 브라우저 내장 PDF 뷰어의 텍스트는 읽을 수 없으므로 Harkback이 PDF를 자체 리더 페이지에서 엽니다(arXiv 논문은 대신 HTML 버전으로 이동). 스캔한 PDF는 컴퓨터에서 OCR로 읽습니다(영어는 내장, 다른 언어는 각각 `cdn.jsdelivr.net`에서 한 번씩 다운로드). 실제 텍스트보다 느리고 덜 정확하며, 손글씨·수식·표는 복원하지 못하고, 복잡한 레이아웃(표, 글자가 있는 그림, 3단 이상)의 문단 감지는 근사치입니다. 컴퓨터에 있는 PDF는 두 가지 승인이 필요합니다. `chrome://extensions`에서 Harkback의 「파일 URL에 대한 액세스 허용」을 켜고, 처음 한 번 리더 페이지에서 「로컬 파일 허용」을 클릭하세요.
- 약어 자동 매칭에는 정식 명칭이 최소 세 단어여야 합니다(`Large Language Model`에서 `LLM`). 같은 분야에서 서로 다른 정식 명칭에 대응하는 약어 둘(예: 서로 다른 두 “GNN”)은 별개의 개념으로 유지됩니다.
- 오탐을 피하기 위해 중국어 이름과 한자로만 쓴 일본어 이름은 세 글자 이상이어야 밑줄이 그어집니다. 가나나 한글이 있는 이름은 두 글자면 됩니다.
- YouTube: 자막(CC)을 켠 `www.youtube.com/watch` 페이지만 읽으며, 페이지를 연 뒤 플레이어가 표시한 자막 줄만 문맥으로 쓸 수 있습니다. 자동 생성 자막은 기술 용어를 자주 잘못 적으며, 잘못 적힌 용어는 내 기록과 일치하지 않습니다. Shorts, 다른 사이트에 삽입된 플레이어, 전체 화면 모드(플레이어가 Harkback의 힌트를 가립니다. 극장 모드를 사용하세요)는 지원하지 않으며, YouTube가 페이지를 바꾸면 Harkback이 업데이트될 때까지 자막을 읽지 못할 수 있습니다.
- GitHub, Notion, Google 문서: 저장소 첫 페이지, 이슈와 풀 리퀘스트(코드 파일 제외), Notion 페이지, 게시된 보기나 모바일 보기의 Google 문서만 읽습니다. Notion은 이미 그려진 블록만 보여 주므로 긴 페이지는 일부만 읽힐 수 있습니다. Google 문서 편집기는 텍스트를 직접 그리기 때문에 읽을 수 없고, 미리보기 화면은 확인되지 않았습니다. 이 사이트들은 예고 없이 레이아웃을 바꿉니다. Harkback이 더 이상 알아보지 못하면 업데이트될 때까지 다른 페이지처럼 읽습니다.
- 매칭할 때 악센트 부호는 무시하지만(“résumé”와 “resume”은 같은 용어), 영어 이외의 언어에는 어간 추출이 없으므로 독일어 복수형 같은 굴절형은 별개의 용어로 취급됩니다.
- 인터페이스는 기본적으로 영어이며, 중국어 간체와 번체, 일본어, 한국어, 스페인어, 프랑스어, 독일어, 브라질 포르투갈어로도 제공됩니다. 설명은 16개 언어로 쓸 수 있으며 설정에서 따로 고릅니다. 내보낸 노트와 Markdown의 라벨은 영어 또는 중국어뿐입니다.

## 저장소 구성

| 경로             | 설명                                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| `packages/spec`  | 이벤트 형식: 상수, zod 스키마, 생성된 JSON 스키마.                                                         |
| `packages/core`  | 순수 로직: 재생, 이름 정규화, 개념 매칭, 재회 선택, 프롬프트, 출력 파싱, JSONL 및 Markdown 내보내기.       |
| `apps/extension` | [WXT](https://wxt.dev)로 만든 Chrome 확장 프로그램: content script, background worker, 기록, 설정, 온보딩. |
| `tools/lint`     | ESLint 설정.                                                                                               |
| `guide`          | 문서: 사용자 가이드, 모델, 개인정보 보호, 아키텍처, 데이터 형식.                                           |

## 개발

```sh
pnpm install
pnpm --filter @harkback/extension dev     # 라이브 리로드
```

풀 리퀘스트를 열기 전에:

```sh
pnpm typecheck     # 모든 패키지
pnpm lint          # ESLint
pnpm test          # 단위 테스트
pnpm check:build   # 프로덕션 빌드: manifest 권한과 content script 크기
pnpm e2e           # Chromium에서의 엔드투엔드 테스트 (먼저 `pnpm exec playwright install chromium`을 한 번 실행)
pnpm format:check  # 서식
```

Microsoft Edge Add-ons용 릴리스를 패키징하려면 `pnpm zip:edge`를 실행합니다(`store/edge/README.md` 참고). Chrome 웹 스토어용 릴리스를 패키징하려면 `apps/extension/package.json`의 `version`을 올린 뒤 `pnpm release`를 실행합니다. 검사를 실행하고, 프로덕션 확장 프로그램을 빌드하고, 패키지를 검증한 뒤 `apps/extension/.output/harkback-<version>-chrome.zip`을 씁니다. zip만 빌드하려면 `tools/package.sh --skip-checks`를 사용합니다.

엔드투엔드 테스트는 빌드한 확장 프로그램을 Chromium에 로드하고, `apps/extension/fixtures`에서 arXiv 페이지를 제공하며, 로컬 스텁 모델 서버와 통신합니다. 논문 읽기, 설명, 기록, 기록 페이지, 다른 논문에서의 재회까지 전체 흐름을 다룹니다. `apps/extension/e2e`를 참고하세요.
