Harkback は、論文や技術文書を読む人のための Chrome 拡張機能です。用語を選択すると、文脈に沿ってその用語を解説します。解説はすべて、ローカルの追記専用ログに保存されます。のちに別のページで同じ用語に出会うと（表記が違っていても）、Harkback は下線を引き、前回どう理解したかを表示します。

> “harken back”：以前の時点に立ち返ること。

## クイックスタート

```sh
git clone https://github.com/zestworks-io/harkback.git && cd harkback
pnpm install && pnpm --filter @harkback/extension build
```

`chrome://extensions` を開き、**デベロッパー モード**をオンにして、**パッケージ化されていない拡張機能を読み込む**を選び、`apps/extension/.output/chrome-mv3` を指定します。次にモデルを選びます。

<details open>
<summary><b>ローカルモデル（無料）</b></summary>

[Ollama](https://ollama.com) をインストールしてモデルを取得し、オンボーディングページで **Ollama** を選びます。「接続をテスト」で、拡張機能を許可するためのコマンドが表示されます。内容がコンピューターの外に出ることはありません。

</details>

<details>
<summary><b>クラウドモデル（自分の API キー）</b></summary>

OpenAI、Anthropic、Google Gemini、xAI Grok、OpenRouter、または OpenAI 互換の独自アドレスを選び、キーを貼り付けます。料金はプロバイダーから直接請求されます。間に Harkback のサーバーはありません。

</details>

あとは任意のページで用語を選択し、`Alt+Shift+E` を押します。詳しくは[インストール](#インストール)と[モデルの接続](#モデルの接続)を参照してください。最初の手順は[はじめにガイド](guide/ja/getting-started.md)にまとめてあります。

## ChatGPT に聞くのではだめ？

用語をチャットボットに貼り付ければ、よい答えが返ってきます。Harkback はより良い答えを出そうとはしません。チャット画面に欠けているもの、つまり**記憶**を加えます。調べた用語はすべて、ページ・引用文・日付に結びついた記録になり、記録同士はつながって、あなただけの知識グラフになります。

|                      | チャットボットに聞く                             | Harkback                                                                      |
| -------------------- | ------------------------------------------------ | ----------------------------------------------------------------------------- |
| **文脈**             | 用語と周辺の文章をコピーし、タブを切り替える     | ページ上で用語を選択すると、その段落と節が一緒に送られ、引用文は検証される    |
| **次に出会ったとき** | 新しいチャットは空っぽ、または聞いたことを忘れる | 後のページで用語に下線が付き、前回の理解が表示される                          |
| **構造**             | 会話ログの山                                     | 別名・前提知識・派生・関連語を持つ概念                                        |
| **定着**             | なし                                             | 記憶モデルで管理される復習キュー：忘れる直前に各用語が戻ってくる              |
| **あなたの記録**     | プロバイダーのアカウントにある                   | ブラウザ内に残る。Markdown、Obsidian のノート、JSONL に書き出せる             |
| **モデルと費用**     | 1 つのサービス、1 つのプラン                     | 対応モデルから自由に選べる：ローカルの Ollama なら無料、または自分の API キー |

Harkback は無料のオープンソース（Apache-2.0）で、サーバーもサブスクリプションもありません。解説を書くモデルは必要です。ローカルモデルは無料で、クラウドモデルはプロバイダーがあなた自身のキーに請求します。

## 機能

- **文脈に沿った解説。** 用語を選択し、「解説」をクリックするか `Alt+Shift+E` を押します。設定したモデルから回答がストリーミングで届き、「原文の定義」（ページがその用語を定義していて、引用文がページの本文と照合済み）または「外部知識」と表示されます。
- **記憶する。** 解説、追加の質問、「理解した／まだ分からない」の印は、それぞれイベントとして IndexedDB に保存されます。ブラウザの外に出るのは、あなたが実行したモデルへのリクエストだけです。
- **追加の質問。** カード上でさらに質問できます。質問は回答の上に残り、やり取りは解説と一緒に保存されます。履歴で全文を見ることができ、検索にもヒットします。数式は組版されます。
- **再会。** 後のページでは、調べたことのある用語に下線が付きます。ホバーすると、いつどこでその用語に出会ったか、何を理解したか、ページ上のどの文字列が一致したかを示す 1 行が表示されます。そこから「思い出した」にしたり、もう一度解説したり、2 つの用法を比較したり、ミュートしたりできます。
- **1 つの概念、複数の表記。** `LLM`、`LLMs`、`the LLM`、`large language model`、`Large-Language Models` は同じ概念です。`β-VAE` と `beta-VAE`、`fine-tuning` と合字の `ﬁne-tuning` も同様です。近い一致は「3 日前に調べた用語はこれですか？」と確認されます。
- **関連語。** モデルが `QLoRA` は `LoRA` の派生だと述べていれば、`QLoRA` だけが出てくるページでも、`LoRA` について理解したことを思い出させます。
- **概念ページ。** 履歴で任意の用語を開くと、理解の度合い、何の上に成り立つか（前提知識）、派生と関連語、そして出会ったすべての場面が見られます。別名の追加、同じもの同士の概念の統合、誤った関係の削除、用語のミュートができます。
- **復習。** 履歴には、期限が来た用語の数を添えた「復習」ボタンがあります。各用語は記憶モデル [FSRS-7](https://github.com/open-spaced-repetition/fsrs4anki) で管理されます。答えを「もう一度」「難しい」「普通」「簡単」で評価すると、忘れる直前に戻ってくるので、簡単な用語は間隔が素早く開き、難しい用語はすぐ戻ってきます。各ボタンには、その用語がいつ戻るかが表示されます。解説を表示する前に、覚えていることを入力できます。任意の「**自分の答えを確認**」ボタンは、どれだけ近かったかをモデルに尋ねます（提案されるのは評価だけで、決めるのはあなたです。設定でオフにできます）。復習はすべてキーボードで行えます。`Space` で解説を表示、`1`〜`4` で評価、`S` でスキップ。両方が期限のとき、ほかの用語の上に成り立つ用語は前提知識の後に出ます。つまずいている用語には、足りないかもしれない前提知識が示されます。再会のヒントで「思い出した」にすると、軽い復習として数えられます。用語の期限が来たときに覚えていたい確率は設定で選べます（既定は 90%）。ツールバーのアイコンに期限の数が表示されます。
- **週間ダイジェスト。** 履歴 →「ダイジェスト」に、1 週間で出会ったものが表示されます。新しい用語と再訪した用語、回答、まだ分からない用語、どこで読んだか、概念間の新しいつながり。あなたの記録からコンピューター上で作られ、モデルは呼び出しません。
- **知っていることの上に積み上げる。** 調べた用語が、すでに理解している用語に近いとき、そのことがモデルに伝わり、ゼロから始めずに違いを説明できます。
- **設計段階からプライベート。** サイトを追加するまで、自動スキャンは arxiv.org に限られます。設定のボタン 1 つで、よく使われる研究サイトをまとめて追加できます。機密サイトはローカルモデルに限定でき、プライベートウィンドウでは記録もスキャンも行いません。
- **持ち運べる記録。** すべてを Markdown、Anki カード、リンクされたノートのフォルダ（概念ごとに 1 ファイル、`[[リンク]]` 付きで Obsidian にそのまま使え、マーカー行より下に書いた内容は次回の書き出し後も残ります）、または公開された JSON スキーマ付きでバージョン管理された JSONL イベントログとして書き出せます。毎週の JSONL バックアップが `Downloads/harkback` に保存され、履歴の **JSONL を読み込む**で復元できます（すでにある記録はスキップされます）。設定で、機密ソースをバックアップや書き出しから除外できます。
- **停止、再試行、モデルの切り替え。** 「停止」ボタンで、回答の生成途中に打ち切れます。失敗すると、カードに「再試行」が表示され、複数のモデルを設定していれば、ほかのモデルごとに「…で再試行」も表示されます。
- **読む前にページをプレビュー。** ツールバーのボタンをクリックするか、`Alt+Shift+P` を押すか、右クリックメニューを使うと、Harkback がページのスキャンを提案します。使うモデルとリモートかどうかが示され、同意するまで何も送られません。1 回のモデル呼び出しでページの重要語を選び出し、あなたの記録が「まだ分からない」「忘れかけ」「初めて」「既知」に仕分けます。「プレビュー」は、知っている用語には以前の解説を、新しい用語にはモデルが書いた短い解説を表示し、何も記録しません。モデルが見るのはページの本文だけで、あなたの概念リストは見ません。機密ページはローカルモデルしか使いません。スキャンはページの先頭 16,000 文字を読み、それより長いページが途中で切られたときはお知らせします。
- **YouTube の字幕。** 設定で YouTube を追加し、字幕をオンにすると、調べたことのある用語が字幕行で下線付きになります。一時停止して用語を選ぶと、見てきた字幕をもとに解説できます。この調べものは再生位置（`12:34`）付きで記録され、履歴・復習・書き出しからその瞬間へ戻れます。サイトを追加するまではオフです。何もダウンロードせず、画面に表示された字幕行だけを読みます。
- **GitHub、Notion、Google ドキュメント。** 設定でサイトを追加すると、そのページは各サイト固有のレイアウトに沿って読まれます。リポジトリの README、issue や pull request のやり取り、Notion のページ、Google ドキュメントの公開ビューまたはモバイルビュー。どの経路で開いても、1 つのドキュメントは 1 つのソースとして扱われ、読まれるのはその本文だけで、周りのメニューは読まれません。
- **非公開らしきページは送る前に確認。** 非公開に見えるページ（非公開の GitHub リポジトリ、公開されていない Notion や Google ドキュメントのページなど）は、「ローカルのみ」か「そのまま送信」を選ぶまで、どのモデルにも送られません。ページ隅の鍵アイコンで状態を確認・変更でき、選択は記録され、そのサイトについて記憶させることもできます。
- **始め方はいくつも。** テキストを選択して「解説」をクリック（マウス、キーボード、タッチの選択に対応）、`Alt+Shift+E` を押す、または右クリックメニューの「解説」を使います。テキストが追加で読み込まれるページや、再読み込みなしで別のページに移るページは、再スキャンされます。
- **モデルは自由に選べる。** Chrome 内蔵の Gemini Nano（コンピューター上で動作、設定不要）、Ollama、OpenAI、Anthropic、Google Gemini、xAI Grok、OpenRouter、または OpenAI 互換の任意のサーバー。Anthropic と Gemini はネイティブ API を使います。

## あなたの知識グラフ

調べるたびに、読んできたものを表すグラフが育ちます。このグラフは汎用モデルの記憶ではなく、あなた自身の読書から作られます。

- **概念がノード。** `LoRA` は、ページがどの表記（`LoRA`、`low-rank adaptation`）を使っても、どの言語で出会っても、1 つのノードです。別名、分野、理解の度合いを持ちます。
- **関係がエッジ。** 用語を調べると、モデルが `variant_of`、`prerequisite`、`related` のリンクを提案します。たとえば `QLoRA` は `LoRA` の派生です。誤ったものは削除でき、同じ概念同士は統合でき、別名も追加できます。
- **すべてが根拠につながる。** 概念には、出会ったすべての場面が並びます。ページ、引用文、日付、あなたの解説、追加の質問のやり取り。
- **グラフは働く。** `QLoRA` だけを挙げるページは `LoRA` を思い出させ、モデルはあなたがすでに知っていることを伝えられて違いを説明でき、復習は概念ごとに管理されます。
- **あなたのもの。** リンク付きのノートのフォルダ（`[[リンク]]`、概念ごとに 1 ファイル）を書き出して Obsidian で開けばグラフが見られます。イベントログ全体を JSONL で書き出すこともできます。

履歴の**グラフ**を開くと、マップとして見られます。概念は理解の度合い（理解した、不安、混乱、新規）で色分けされ、前提知識と派生が矢印で示されます。分野、理解の度合い、最後に調べた時期で絞り込めます。ドラッグで移動、スクロールで拡大縮小、クリックで概念を開きます。概念ページや、書き出したあとの Obsidian からも見られます。

## 仕組み

```
 読む                解説する                記憶する                 思い出す
 ────                ───────                 ────────                 ──────
 content script  →   background worker   →   追記専用イベントログ  →  マッチャーが次のページで
 ページの本文を      サイトの機密度で        (IndexedDB)。再生して     既知の名前を探し、表示する
 抽出し、選択を      モデルを振り分け、      概念・別名・遭遇に        価値のある概念を選んで
 追跡                回答をストリーム、      なる                      下線とカードを描く
                     概念を解決
```

1. **読む。** content script がページの読める本文を抽出し（arXiv では LaTeXML の構造、それ以外では Readability）、テキストのオフセットから DOM ノードへの対応表を保持します。
2. **解説する。** background worker がサイトのルールを確認し、モデルを選び、ローカルのレート制限をかけて、用語を段落とともに送ります。プロンプトには既知の概念が候補として並ぶので、モデルは「これは c1 と同じ概念」と答えられます。返答の解析は寛容です。途中で切れたカード、末尾のカンマ、装飾付きのラベルも許容されます。
3. **記憶する。** 結果はイベント（`concept.created`、`encounter.created`、`edge.proposed` など）になります。概念・別名・統合はログを再生して導かれ、保存されることはないので、より良い照合ルールは過去の記録も改善します。
4. **思い出す。** ページごとに Aho-Corasick マッチャーが、既知のすべての名前と略語をテキストから探します。そのうえで再会の選択が、実用性を保つルールを適用します。調べたページでは出さない、最小間隔以内には出さない、ミュートした概念はミュートのまま、曖昧な略語はページ上に同じ分野の 2 つ目の用語が必要、というルールです。

## インストール

Node 22 以降と [pnpm](https://pnpm.io) が必要です。ストアにはまだ公開していないため、ソースから拡張機能を読み込みます。

```sh
# リポジトリのルートで
pnpm install
pnpm --filter @harkback/extension build
```

`chrome://extensions` を開き、**デベロッパー モード**を有効にして、**パッケージ化されていない拡張機能を読み込む**を選び、`apps/extension/.output/chrome-mv3` を指定します。インストールするとオンボーディングページが開きます。

**Microsoft Edge。** `apps/extension` で `pnpm build -b edge`（または `pnpm zip:edge`）を実行し、`edge://extensions` を開いて**開発者モード**をオンにし、**展開して読み込み**を選んで `apps/extension/.output/edge-mv3` を指定します。Edge には Chrome 内蔵のモデルがない場合があります。セットアップで別のモデルを選んでください。

## モデルの接続

オンボーディングは 3 ステップです。**ようこそ**（再会のヒントの例と、モデルを呼ばずに試せる内蔵の解説例）、**プライバシー**（テキストの送信先。同意のチェックボックスをオンにするまで「次へ」は有効になりません）、**モデル**（プロバイダーを選んで「完了」）。オンボーディングをやり直すと、コピーを追加せず、すでにあるモデルを更新します。モデルの追加やオプションの変更は、あとから設定ページでできます。設定ページでは、レート制限、再会のヒント、モデルが応答しないときに何秒でリクエストを諦めるかも設定できます。

![モデルが 1 つある設定ページ：名前、モデル、アドレス、API キー、「接続をテスト」ボタン](assets/settings.png)

| プロバイダー               | Base URL                                           | 備考                                                                                                                                                 |
| -------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ollama                     | `http://127.0.0.1:11434/v1`                        | ローカル、キー不要。下記参照。                                                                                                                       |
| Chrome 内蔵（Gemini Nano） | なし                                               | このコンピューター上で動作、キー不要。セットアップまたは設定でダウンロード。小さなモデルで、クラウドモデルより遅く、英語・スペイン語・日本語が得意。 |
| OpenAI                     | `https://api.openai.com/v1`                        | API キーが必要。                                                                                                                                     |
| Anthropic                  | `https://api.anthropic.com/v1`                     | API キーが必要。                                                                                                                                     |
| Google Gemini              | `https://generativelanguage.googleapis.com/v1beta` | API キーが必要。                                                                                                                                     |
| xAI Grok                   | `https://api.x.ai/v1`                              | API キーが必要。                                                                                                                                     |
| OpenRouter                 | `https://openrouter.ai/api/v1`                     | API キーが必要。                                                                                                                                     |
| カスタム                   | 任意のアドレス                                     | `https`。ただしこのコンピューターと自分のネットワーク（`192.168.x.x`、`10.x.x.x`、`name.local`、Tailscale）は除く。                                  |

プロバイダーごとに独自の形式を使います。Anthropic と Google Gemini はネイティブ API、それ以外（Ollama、Grok、OpenRouter、社内プロキシなどの独自アドレスを含む）は OpenAI 互換形式です。プロバイダーを選ぶとそのアドレスが入力され、あとから編集もできます。そのほかの OpenAI 互換サービスには**カスタム**を選んでください。

モデルのアドレスへのアクセスは、初めてテストまたは保存するときに Chrome が許可を求めます。拒否した場合、解説カードはネットワークエラーで失敗する代わりに、そのことを伝えます。

**Ollama** は、拡張機能のオリジンが許可されていない限り、ブラウザ拡張機能からのリクエストを拒否します。「接続をテスト」ボタンに、お使いのシステム向けの正確なコマンドが表示されます。たとえば macOS では次のとおりです。

```sh
launchctl setenv OLLAMA_ORIGINS "chrome-extension://<your-extension-id>"
```

そのあと Ollama を再起動します。

## 使い方

| やりたいこと                     | 操作                                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 用語を解説する                   | 選択して**解説**をクリック、または `Alt+Shift+E`。                                                                                         |
| さらに質問する                   | カードの**質問する**を使います。質問と回答は解説と一緒に保存されます。                                                                     |
| arXiv 以外のページをスキャンする | ツールバーのボタンをクリック、または設定の「サイト」でそのサイトを許可して自動スキャン。                                                   |
| PDF を読む                       | PDF 上でツールバーのボタンをクリック：arXiv の論文は HTML で、そのほかの PDF はリーダーで開きます。                                        |
| 調べたものを見る                 | 設定ページまたはオンボーディングページから履歴ページを開きます。リアルタイムで更新され、各項目のソースタイトルは元のページにリンクします。 |
| 記録を保管する                   | 履歴ページ →**Markdown を書き出す**、**Anki カードを書き出す**、**今すぐ JSONL をバックアップ**。                                          |
| バックアップから復元する         | 履歴ページ →**JSONL を読み込む**。                                                                                                         |
| 概念のつながりを見る             | 履歴ページ →**グラフ**。                                                                                                                   |
| 用語の下線を消す                 | 下線にホバー →**今後表示しない**。                                                                                                         |
| ソースをリモートモデルから外す   | カード →**このソースを機密にする**、または設定でそのサイトに機密ルールを追加。                                                             |
| 非公開らしきページを決着させる   | ページ隅の鍵アイコン、または最初の解説時の質問：**ローカルのみ**か**そのまま送信**。                                                       |

## プライバシー

- 解説を求めると、選択したテキスト、その段落、節、ページのタイトルが、設定したモデルサービスに、そのプロバイダーの規約のもとで送られます。
- 復習では、任意の「**自分の答えを確認**」ボタンは、押したときにだけ、用語、入力した答え、保存済みの解説をモデルに送ります。設定でオフにすると、ボタンは表示されません。解説と同じモデルと機密ソースのルールに従います。
- 記録はこのブラウザ内に残ります。バックアップに含まれるのは記録だけで、設定や API キーは含まれません。
- ページが自動でスキャンされるのは arxiv.org だけです。それ以外では、ボタンをクリックするか、`Alt+Shift+E` を押すか、サイトを許可する必要があります。
- 機密ソースの内容は、あとの比較の文脈としてを含め、ローカルでないモデルには決して送られません。自分のネットワーク上のサーバーもローカルではないものとして扱います。ソースは、履歴の項目で通常に戻すまで機密のままです。
- 非公開に見えるページ（非公開の GitHub リポジトリ、公開されていない Notion や Google ドキュメントのページ）は、選択するまでどのモデルにも送られません。サイトがどちらとも示していないページは、Notion と Google ドキュメントでは確認され、GitHub では確認されません。ページが自分自身について示すことはヒントにすぎないので、重要なときはサイトを機密にしてください。
- 設定で、機密ソースをバックアップと書き出しから除外できます。
- プライベートウィンドウでは解説はしますが、記録・スキャン・再会の表示は行いません。
- 再会の下線はページの中にあるため、ページ自身のスクリプトは、どの用語の記録があるかを推測できる可能性があります。
- 解説を削除すると、アプリ内では消えますが、ディスク上に痕跡が残る場合があり、書き出し済みのバックアップは取り消せません。
- API キーは拡張機能のストレージに**暗号化されずに**保存されます。

拡張機能内に表示される注意書きが正本です：[`apps/extension/src/lib/pages/privacy.ts`](apps/extension/src/lib/pages/privacy.ts)。

## あなたのデータ

すべては追記専用ログのイベントです。形式は公開されています。

- イベントの種類とペイロード：[`packages/spec`](packages/spec)、および生成された [JSON スキーマ](packages/spec/schema/event.schema.json)。
- 再生、照合、書き出し：[`packages/core`](packages/core)。ブラウザへの依存がなく、単体で使えます。

概念と別名はログから導かれるので、JSONL バックアップは、あなたが知っていることの完全で持ち運べるコピーです。

## 制限事項

- Chrome と Microsoft Edge（Manifest V3）。Firefox と Safari は非対応です。Chrome 内蔵モデルはすべてのブラウザで使えるわけではなく、Edge では別のモデルが必要です。
- 解説は選んだモデルに依存します。小さなローカルモデルは概念カードの質が下がることがあり、再会の質は下がりますが、記録が壊れることはありません。
- ブラウザ内蔵の PDF ビューアのテキストは読めないため、Harkback は PDF を独自のリーダーページで開きます（arXiv の論文は代わりに HTML 版へ）。スキャンされた PDF は、コンピューター上で OCR により読み取ります（英語は内蔵、そのほかの言語は `cdn.jsdelivr.net` から 1 つずつダウンロード）。本物のテキストより遅くて不正確で、手書き・数式・表は復元できず、複雑なレイアウト（表、文字を含む図、3 段以上の組み）の段落検出は近似的です。コンピューター上の PDF には 2 つの承認が必要です。`chrome://extensions` で Harkback の「ファイルの URL へのアクセスを許可する」をオンにし、初回にリーダーページで「ローカルファイルを許可」をクリックします。
- 略語の自動照合には、正式名称に 3 語以上が必要です（`Large Language Model` から `LLM`）。同じ分野で異なる正式名称に対応する 2 つの略語（たとえば別々の「GNN」）は、別の概念として扱われます。
- 誤検出を避けるため、中国語の名前と、漢字だけで書かれた日本語の名前は、3 文字以上でないと下線が引かれません。かなやハングルを含む名前は 2 文字で足ります。
- YouTube：字幕（CC）をオンにした `www.youtube.com/watch` のページだけが読まれ、ページを開いてからプレーヤーが表示した字幕行だけが文脈として使えます。自動生成の字幕は専門用語を誤記しがちで、誤記された用語は記録と一致しません。ショート動画、他サイトの埋め込みプレーヤー、全画面モード（プレーヤーが Harkback のヒントを隠します。シアターモードをお使いください）は非対応で、YouTube のページ変更により、Harkback が更新されるまで字幕が読めなくなることがあります。
- GitHub、Notion、Google ドキュメント：読まれるのは、リポジトリのトップページ、issue と pull request（コードファイルは除く）、Notion のページ、公開ビューまたはモバイルビューの Google ドキュメントだけです。Notion は描画済みのブロックしか表示しないため、長いページは一部しか読めないことがあります。Google ドキュメントのエディターはテキストを描画しているため読めず、プレビュー表示は未確認です。これらのサイトは予告なくレイアウトを変えます。Harkback が認識できなくなったときは、更新されるまで、ほかのページと同じように読みます。
- 照合ではアクセント記号を無視します（“résumé” と “resume” は同じ用語）が、英語以外の言語では語幹処理がないため、ドイツ語の複数形のような屈折形は別の用語として扱われます。
- インターフェースは既定で英語で、簡体字・繁体字中国語、日本語、韓国語、スペイン語、フランス語、ドイツ語、ブラジルのポルトガル語にも対応しています。解説は 16 の言語で書けて、設定で別に選びます。書き出したノートと Markdown のラベルは英語か中国語だけです。

## 開発

```sh
pnpm install
pnpm --filter @harkback/extension dev     # ライブリロード
```

pull request を開く前に：

```sh
pnpm typecheck     # すべてのパッケージ
pnpm lint          # ESLint
pnpm test          # ユニットテスト
pnpm check:build   # 本番ビルド：manifest の権限と content script のサイズ
pnpm e2e           # Chromium でのエンドツーエンドテスト（一度 `pnpm exec playwright install chromium` を実行）
pnpm format:check  # フォーマット
```

Microsoft Edge Add-ons 向けのリリースをパッケージ化するには、`pnpm zip:edge` を実行します（`store/edge/README.md` を参照）。Chrome ウェブストア向けのリリースをパッケージ化するには、`apps/extension/package.json` の `version` を上げてから `pnpm release` を実行します。チェックを実行し、本番用の拡張機能をビルドし、パッケージを検証して、`apps/extension/.output/harkback-<version>-chrome.zip` を書き出します。zip だけをビルドするには `tools/package.sh --skip-checks` を使います。

エンドツーエンドテストは、ビルドした拡張機能を Chromium に読み込み、`apps/extension/fixtures` から arXiv のページを配信し、ローカルのスタブモデルサーバーと通信します。論文を読む、解説する、記録する、履歴ページ、ほかの論文での再会という全体のループを網羅しています。`apps/extension/e2e` を参照してください。
