Understanding adapters

Adapters are small modules inserted into a frozen network. They let one base model serve many downstream tasks without copying all of its weights, which keeps storage costs low and makes switching between tasks cheap. Each task only needs its own small set of adapter parameters.

LoRA is a popular adapter that learns a low-rank update to existing weight matrices. Because the update can be merged back into the weights after training, it adds no inference latency, unlike bottleneck adapters that insert extra layers.
