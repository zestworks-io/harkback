# はじめに

何もない状態から、最初の用語を記憶するまで 5 分です。

> これは[英語版のはじめに](../getting-started.md)の日本語訳です。ほかのページは今のところ英語のみです。[英語のドキュメント](../README.md)をご覧ください。

## 1. インストール

Harkback は Chrome 拡張機能（Manifest V3）です。まだストアには掲載されていないため、ソースから読み込みます。Node 22 以降と [pnpm](https://pnpm.io) が必要です。

```sh
git clone https://github.com/zestworks-io/harkback.git
cd harkback
pnpm install
pnpm --filter @harkback/extension build
```

`chrome://extensions` を開き、**デベロッパー モード**をオンにして、**パッケージ化されていない拡張機能を読み込む**を選び、`apps/extension/.output/chrome-mv3` を指定します。オンボーディングのページが自動的に開きます。

新しいコードを取得したら、もう一度ビルドして、拡張機能のカードにある再読み込みアイコンを押してください。

## 2. モデルを接続する

Harkback にはサーバーがありません。解説を書くモデルが必要で、どれを使うかは自分で選びます。オンボーディングのページは 3 ステップです。終わったステップには ✓ が付き、クリックするとそこに戻れます。

1. **ようこそ。** 再会ヒントの例を見て、下線付きの用語をクリックすると、解説がどう表示されるかを確認できます。モデルは呼び出されません。
2. **プライバシー。** テキストがどこに送られるかを読み、同意のチェックボックスをオンにします。オンにするまで**次へ**は押せません。
3. **モデル。** プロバイダーを選ぶとアドレスが入力されます。プロバイダーが必要とする場合は API キーを貼り付けます（Ollama と Chrome 内蔵モデルでは不要です）。**接続をテスト**を押すと、Chrome が Harkback にそのアドレスへのアクセスを許可するか尋ねるので、許可してください。テスト中はスピナーと「接続中…」が表示され、終わるまでボタンは無効になります。そのあと**設定を完了**を押します。

**Chrome 内蔵（Gemini Nano）**にはアドレスもキーも不要です。選ぶとモデルの状態と**モデルをダウンロード**ボタンが表示され、ダウンロードが終わるまで**設定を完了**は待機します。お使いのコンピューター上で動く小さなモデルなので、クラウドのモデルより遅く（特に最初のリクエスト）、答えも簡素になります。短い解説に向いています。

モデルの追加やオプションの変更は、あとから設定ページでできます。オンボーディングを再実行すると、すでにあるモデルが更新され、2 つ目が追加されることはありません。

いちばん手軽な無料の選択肢は、ローカルの [Ollama](https://ollama.com) モデルです。Ollama は拡張機能のオリジンを許可するまでブラウザ拡張機能からのリクエストを拒否するため、もう 1 手順が必要です。テストボタンが、お使いのシステム向けの正確なコマンドを表示します。各プロバイダーの説明と、家庭内ネットワークの別のコンピューターでモデルを動かす方法は、[モデルとプロバイダー](../models.md)を参照してください。

インターフェースは英語で始まります。インターフェースの言語と解説の言語は、オンボーディングまたは設定ページで変更できます。

## 3. 用語を解説する

1. [arxiv.org](https://arxiv.org) で論文を開きます。arXiv のページは自動的にスキャンされます。
2. `LoRA` などの用語を選択します。
3. 選択範囲の横の**解説**をクリックするか、`Alt+Shift+E` を押します。
4. 答えが流れるように表示されるのを読みます。緑のタグはページ自体がその用語を定義していること、黄色のタグは答えがモデル自身の知識によるものであることを示します。
5. **理解した**または**まだ分からない**を押します。この回答がその用語の最初の評価になり、Harkback がいつ復習に戻すかを決めます。

そのほかの始め方：選択したテキストの右クリックメニュー、キーボードやタッチで行った選択。

## 4. 用語にまた出会う

`LoRA`、`low-rank adaptation`、`LoRAs` に触れている別の論文を開くと、その用語に下線が付きます。ポインターを重ねると、いつどこで調べたか、そのときどう理解したかが表示されます。覚えているとマークする、もう一度解説する、2 つの用法を比べる、表示しないようにする、のいずれかができます。

## 5. これまでの蓄積を見る

**履歴**ページ（設定とオンボーディングからリンクされています）を開きます。用語が概念ごとに一覧表示され、検索、追加の質問の会話、復習キュー、概念同士のつながりを示すグラフがあります。ここから記録を書き出したり、バックアップから復元したりすることもできます。

## arXiv にないものを読む

- **ウェブページ：**ツールバーのボタンを一度クリックします。以後そのサイトを自動でスキャンするには、設定の*サイト*に追加します。
- **PDF：**PDF 上でツールバーのボタンをクリックします。arXiv の PDF は HTML 版で開き、そのほかの PDF は Harkback 独自のリーダーで開きます。コンピューター上の PDF は、初回に 2 つの承認が必要です。[トラブルシューティング](../troubleshooting.md#a-pdf-on-my-computer-will-not-open)を参照してください。
- **機密のもの：**先にそのサイトまたは出典を機密としてマークします。[プライバシーと機密の出典](../privacy.md)を参照してください。
