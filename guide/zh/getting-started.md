# 快速开始

五分钟，从零到记住你的第一个术语。

> 这是[英文版快速开始](../getting-started.md)的中文翻译。其他文档目前只有英文版，见[英文文档](../README.md)。

## 1. 安装

Harkback 是 Chrome 扩展（Manifest V3）。目前还没有商店页面，所以需要从源码加载。你需要 Node 22 或更新版本，以及 [pnpm](https://pnpm.io)。

```sh
git clone https://github.com/zestworks-io/harkback.git
cd harkback
pnpm install
pnpm --filter @harkback/extension build
```

打开 `chrome://extensions`，打开**开发者模式**，选择**加载已解压的扩展程序**，然后选中 `apps/extension/.output/chrome-mv3`。引导页会自动打开。

拉取新代码后，重新构建一次，并在扩展卡片上点刷新图标。

## 2. 连接模型

Harkback 没有服务器。它需要一个模型来写解释，由你来选择。引导页是三步流程；完成的步骤会显示 ✓，点击即可回到那一步。

1. **欢迎。** 查看一个示例提示，点击带下划线的术语，看看解释是什么样子。这一步不会调用任何模型。
2. **隐私。** 阅读你的文字会发送到哪里，并勾选同意框。勾选之前，**下一步**保持不可用。
3. **模型。** 选择一个服务商，地址会自动填入。如果服务商需要 API key，请粘贴（Ollama 和 Chrome 内置模型不需要）。点**测试连接**，Chrome 会询问是否允许 Harkback 访问该地址；请允许。测试进行时会显示转圈和「连接中…」，按钮在结束前不可用。然后点**完成设置**。

**Chrome 内置模型（Gemini Nano）**不需要地址或 key。选中它会显示模型状态和**下载模型**按钮；**完成设置**会等到下载结束。它是在你电脑上运行的小模型，所以比云端模型慢，尤其是第一次请求，回答也更简单，适合简短的解释。

之后可以在设置页添加更多模型、更改选项。再次运行引导页会更新你已有的模型，不会再添加一份。

最简单的免费选择是本机的 [Ollama](https://ollama.com) 模型。它多一步操作，因为在你允许扩展的来源之前，Ollama 会拒绝来自浏览器扩展的请求。测试按钮会显示适合你系统的具体命令。各服务商的说明，以及在家庭网络中的另一台电脑上运行模型的方法，见[模型与服务商](../models.md)。

界面默认是英文。你可以在引导页或设置页更改界面语言和解释所用的语言。

## 3. 解释一个术语

1. 在 [arxiv.org](https://arxiv.org) 打开一篇论文。arXiv 页面会自动扫描。
2. 选中一个术语，例如 `LoRA`。
3. 点选区旁的**解释**，或按 `Alt+Shift+E`。
4. 看着答案逐字流出。绿色标签表示页面自己定义了这个术语；黄色标签表示答案来自模型自己的知识。
5. 点**懂了**或**还是不懂**。这个回答是该术语的第一次评分，决定 Harkback 何时让你复习它。

其他开始方式：选中文字后的右键菜单，以及用键盘或触摸做的选择。

## 4. 再次遇到这个术语

打开另一篇提到 `LoRA`、`low-rank adaptation` 或 `LoRAs` 的论文，这个术语会带下划线。把鼠标移上去，可以看到你何时何地查过它、当时是怎么理解的。你可以标记为记得、再解释一次、对比两处用法，或者不再提示。

## 5. 看看你积累了什么

打开**历史**页（从设置和引导页都能进入）。它按概念列出每个术语，支持搜索、追问对话、复习队列，以及概念之间关系的图。你也可以在这里导出记录，或从备份恢复。

## 阅读不在 arXiv 上的内容

- **网页：** 点一下工具栏按钮。要让某个网站以后自动扫描，请在设置的*网站*中添加它。
- **PDF：** 在 PDF 上点工具栏按钮。arXiv 的 PDF 会打开对应的 HTML 版本；其他 PDF 会在 Harkback 自己的阅读页中打开。电脑上的 PDF 第一次需要两次授权，见[故障排查](../troubleshooting.md#a-pdf-on-my-computer-will-not-open)。
- **机密内容：** 先把网站或来源标为敏感。见[隐私与敏感来源](../privacy.md)。
