# 시작하기

아무것도 없는 상태에서 첫 용어를 기억하기까지 5분이면 됩니다.

> 이 문서는 [영어판 시작하기](../getting-started.md)의 한국어 번역입니다. 다른 문서는 아직 영어로만 제공됩니다. [영어 문서](../README.md)를 참고하세요.

## 1. 설치

Harkback은 Chrome 확장 프로그램(Manifest V3)입니다. 아직 스토어에 등록되어 있지 않으므로 소스에서 불러옵니다. Node 22 이상과 [pnpm](https://pnpm.io)이 필요합니다.

```sh
git clone https://github.com/zestworks-io/harkback.git
cd harkback
pnpm install
pnpm --filter @harkback/extension build
```

`chrome://extensions`를 열고 **개발자 모드**를 켠 다음, **압축해제된 확장 프로그램을 로드합니다**를 선택해 `apps/extension/.output/chrome-mv3`를 지정합니다. 온보딩 페이지가 저절로 열립니다.

새 코드를 받은 뒤에는 다시 빌드하고, 확장 프로그램 카드의 새로고침 아이콘을 누르세요.

## 2. 모델 연결

Harkback에는 서버가 없습니다. 설명을 쓸 모델이 필요하며, 어떤 모델을 쓸지는 직접 고릅니다. 온보딩 페이지는 3단계로 이루어져 있습니다. 끝낸 단계에는 ✓가 표시되고, 클릭하면 그 단계로 돌아갈 수 있습니다.

1. **시작.** 다시 만남 힌트의 예를 보고, 밑줄 친 용어를 클릭해 설명이 어떻게 보이는지 확인합니다. 모델은 호출되지 않습니다.
2. **개인정보 보호.** 텍스트가 어디로 전송되는지 읽고 동의 상자를 선택합니다. 선택하기 전까지 **다음**은 비활성 상태입니다.
3. **모델.** 제공업체를 고르면 주소가 채워집니다. 제공업체가 필요로 하면 API 키를 붙여 넣습니다(Ollama와 Chrome 내장 모델은 필요 없습니다). **연결 테스트**를 누르면 Chrome이 Harkback이 그 주소에 접근해도 되는지 묻습니다. 허용하세요. 테스트하는 동안 스피너와 "연결 중…"이 표시되고, 끝날 때까지 버튼은 비활성입니다. 그런 다음 **설정 완료**를 누릅니다.

**Chrome 내장(Gemini Nano)**은 주소도 키도 필요 없습니다. 선택하면 모델 상태와 **모델 내려받기** 버튼이 표시되며, **설정 완료**는 내려받기가 끝날 때까지 기다립니다. 내 컴퓨터에서 실행되는 작은 모델이라서 클라우드 모델보다 느리고(특히 첫 요청), 답변도 더 단순합니다. 짧은 설명에 알맞습니다.

모델을 더 추가하거나 옵션을 바꾸는 것은 나중에 설정 페이지에서 할 수 있습니다. 온보딩을 다시 실행하면 이미 있는 모델이 갱신되며, 두 번째 사본이 추가되지는 않습니다.

가장 쉬운 무료 선택지는 로컬 [Ollama](https://ollama.com) 모델입니다. Ollama는 확장 프로그램의 출처를 허용하기 전에는 브라우저 확장 프로그램의 요청을 거부하므로 한 단계가 더 필요합니다. 테스트 버튼이 내 시스템에 맞는 정확한 명령을 보여 줍니다. 모든 제공업체와, 집 안 네트워크의 다른 컴퓨터에서 모델을 실행하는 방법은 [모델과 제공업체](../models.md)를 참고하세요.

인터페이스는 영어로 시작합니다. 인터페이스 언어와 설명 언어는 온보딩 또는 설정 페이지에서 바꿀 수 있습니다.

## 3. 용어 설명받기

1. [arxiv.org](https://arxiv.org)에서 논문을 엽니다. arXiv 페이지는 자동으로 스캔됩니다.
2. `LoRA` 같은 용어를 선택합니다.
3. 선택한 부분 옆의 **설명**을 클릭하거나 `Alt+Shift+E`를 누릅니다.
4. 답변이 흘러나오는 것을 읽습니다. 초록색 태그는 페이지 자체가 그 용어를 정의한다는 뜻이고, 노란색 태그는 답변이 모델 자신의 지식에서 나왔다는 뜻입니다.
5. **이해함** 또는 **아직 헷갈림**을 누릅니다. 이 답이 그 용어의 첫 평가가 되어, Harkback이 언제 복습하러 되돌려 보낼지를 정합니다.

다른 시작 방법: 선택한 텍스트의 오른쪽 클릭 메뉴, 키보드나 터치로 한 선택.

## 4. 용어를 다시 만나기

`LoRA`, `low-rank adaptation` 또는 `LoRAs`를 언급하는 다른 논문을 열면 그 용어에 밑줄이 표시됩니다. 위에 마우스를 올리면 언제 어디서 찾아봤는지, 그때 어떻게 이해했는지 볼 수 있습니다. 기억남으로 표시하거나, 다시 설명하거나, 두 용법을 비교하거나, 더 이상 표시하지 않도록 할 수 있습니다.

## 5. 쌓아 둔 것 보기

**기록** 페이지(설정과 온보딩에서 링크됩니다)를 엽니다. 용어가 개념별로 나열되고, 검색, 추가 질문 대화, 복습 대기열, 개념들이 어떻게 이어지는지 보여 주는 그래프가 있습니다. 여기서 기록을 내보내거나 백업에서 복원할 수도 있습니다.

## arXiv에 없는 것 읽기

- **웹 페이지:** 도구 모음 버튼을 한 번 클릭합니다. 이후 그 사이트를 자동으로 스캔하려면 설정의 *사이트*에 추가하세요.
- **PDF:** PDF에서 도구 모음 버튼을 클릭합니다. arXiv의 PDF는 HTML 버전으로 열리고, 다른 PDF는 Harkback의 자체 리더에서 열립니다. 컴퓨터에 있는 PDF는 처음에 두 번의 승인이 필요합니다. [문제 해결](../troubleshooting.md#a-pdf-on-my-computer-will-not-open)을 참고하세요.
- **기밀 자료:** 먼저 그 사이트나 출처를 민감한 것으로 표시하세요. [개인정보와 민감한 출처](../privacy.md)를 참고하세요.
