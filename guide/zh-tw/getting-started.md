# 快速開始

五分鐘，從零到記住你的第一個術語。

> 這是[英文版快速開始](../getting-started.md)的中文翻譯。其他文件目前只有英文版，見[英文文件](../README.md)。

## 1. 安裝

Harkback 是 Chrome 擴充功能（Manifest V3）。目前還沒有商店頁面，所以需要從原始碼載入。你需要 Node 22 或更新版本，以及 [pnpm](https://pnpm.io)。

```sh
git clone https://github.com/zestworks-io/harkback.git
cd harkback
pnpm install
pnpm --filter @harkback/extension build
```

開啟 `chrome://extensions`，開啟**開發人員模式**，選擇**載入未封裝項目**，然後選取 `apps/extension/.output/chrome-mv3`。引導頁會自動開啟。

拉取新程式碼後，重新建置一次，並在擴充功能卡片上按重新載入圖示。

## 2. 連接模型

Harkback 沒有伺服器。它需要一個模型來寫解釋，由你來選擇。引導頁是三步流程；完成的步驟會顯示 ✓，點擊即可回到那一步。

1. **歡迎。** 查看一個範例提示，點擊帶底線的術語，看看解釋是什麼樣子。這一步不會呼叫任何模型。
2. **隱私。** 閱讀你的文字會傳送到哪裡，並勾選同意框。勾選之前，**下一步**保持無法使用。
3. **模型。** 選擇一個服務供應商，位址會自動填入。如果供應商需要 API 金鑰，請貼上（Ollama 和 Chrome 內建模型不需要）。按**測試連線**，Chrome 會詢問是否允許 Harkback 存取該位址；請允許。測試進行時會顯示轉圈和「連線中…」，按鈕在結束前無法使用。然後按**完成設定**。

**Chrome 內建模型（Gemini Nano）**不需要位址或金鑰。選取它會顯示模型狀態和**下載模型**按鈕；**完成設定**會等到下載結束。它是在你電腦上執行的小模型，所以比雲端模型慢，尤其是第一次請求，回答也較簡單，適合簡短的解釋。

之後可以在設定頁新增更多模型、變更選項。再次執行引導頁會更新你已有的模型，不會再新增一份。

最簡單的免費選擇是本機的 [Ollama](https://ollama.com) 模型。它多一個步驟，因為在你允許擴充功能的來源之前，Ollama 會拒絕來自瀏覽器擴充功能的請求。測試按鈕會顯示適合你系統的具體指令。各服務供應商的說明，以及在家庭網路中的另一台電腦上執行模型的方法，見[模型與服務供應商](../models.md)。

介面預設是英文。你可以在引導頁或設定頁變更介面語言和解釋所用的語言。

## 3. 解釋一個術語

1. 在 [arxiv.org](https://arxiv.org) 開啟一篇論文。arXiv 頁面會自動掃描。
2. 選取一個術語，例如 `LoRA`。
3. 按選取範圍旁的**解釋**，或按 `Alt+Shift+E`。
4. 看著答案逐字流出。綠色標籤表示頁面自己定義了這個術語；黃色標籤表示答案來自模型自己的知識。
5. 按**懂了**或**還是不懂**。這個回答是該術語的第一次評分，決定 Harkback 何時讓你複習它。

其他開始方式：選取文字後的右鍵選單，以及用鍵盤或觸控做的選取。

## 4. 再次遇到這個術語

開啟另一篇提到 `LoRA`、`low-rank adaptation` 或 `LoRAs` 的論文，這個術語會帶底線。把滑鼠移上去，可以看到你何時何地查過它、當時是怎麼理解的。你可以標記為記得、再解釋一次、比較兩處用法，或者不再提示。

## 5. 看看你累積了什麼

開啟**歷史**頁（從設定和引導頁都能進入）。它按概念列出每個術語，支援搜尋、追問對話、複習佇列，以及概念之間關係的圖。你也可以在這裡匯出紀錄，或從備份還原。

## 閱讀不在 arXiv 上的內容

- **網頁：** 按一下工具列按鈕。要讓某個網站之後自動掃描，請在設定的*網站*中新增它。
- **PDF：** 在 PDF 上按工具列按鈕。arXiv 的 PDF 會開啟對應的 HTML 版本；其他 PDF 會在 Harkback 自己的閱讀頁中開啟。電腦上的 PDF 第一次需要兩次授權，見[疑難排解](../troubleshooting.md#a-pdf-on-my-computer-will-not-open)。
- **機密內容：** 先把網站或來源標為敏感。見[隱私與敏感來源](../privacy.md)。
